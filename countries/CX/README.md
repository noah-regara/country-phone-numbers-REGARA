# Christmas Island — Phone Number Formats

**ISO 3166-1:** `CX` / `CXR`  
**Country calling code:** +61  
**Trunk prefix:** `0`  
**International call prefix:** `0011`  
**National significant number:** 9 digits

## Formatting

```
National:      (08) 9164 XXXX
International: +61 8 9164 XXXX (trunk 0 dropped)
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Christmas Island (08 9164) | `(08) 9164 XXXX` | `+61 8 9164 XXXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+61891641234` | `+61 8 9164 1234` | `(08) 9164 1234` | Christmas Island — the dedicated 9164 exchange within Australia's 08 area code |

## Notes

- Christmas Island is an Australian external territory inside the +61 plan; it has no country code of its own.
- It used +672 until October 1994, when it migrated to +61 and eventually settled on the 08 9164 range.
- Administered by ACMA under the Australian Telecommunications Numbering Plan.
