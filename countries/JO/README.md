# Jordan — Phone Number Formats

**ISO 3166-1:** `JO` / `JOR`  
**Country calling code:** +962  
**Trunk prefix:** `0`  
**International call prefix:** `00`  
**National significant number:** 8 or 9 digits

## Formatting

```
National:      0A XXX XXXX (landline) / 07X XXX XXXX (mobile)
International: +962 A XXX XXXX (trunk 0 dropped)
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Amman (6) | `06 XXX XXXX` | `+962 6 XXX XXXX` |
| North — Irbid, Ajloun, Jerash, Mafraq (2) | `02 XXX XXXX` | `+962 2 XXX XXXX` |
| South — Karak, Ma'an, Aqaba, Petra (3); Zarqa (5) | `03 XXX XXXX` | `+962 3 XXX XXXX` |
| Mobile (77 Orange, 78 Umniah, 79 Zain) | `079 XXX XXXX` | `+962 79 XXX XXXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+96265555555` | `+962 6 555 5555` | `06 555 5555` | Amman — area code 6 |
| fixed-line | `+96221234567` | `+962 2 123 4567` | `02 123 4567` | Irbid and the north — area code 2 |
| mobile | `+962791234567` | `+962 79 123 4567` | `079 123 4567` | Mobile — 79 is a Zain range; 77 Orange, 78 Umniah |

## Notes

- Closed plan with single-digit geographic area codes; mobile numbers use 2-digit codes starting with 7.
- 8xx and 9xx ranges are reserved for free and service lines.
