# Réunion — Phone Number Formats

**ISO 3166-1:** `RE` / `REU`  
**Country calling code:** +262  
**Trunk prefix:** `0`  
**International call prefix:** `00`  
**National significant number:** 9 digits

## Formatting

```
National:      0262 XX XX XX
International: +262 262 XX XX XX
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Fixed line (0262, 0263) | `0262 XX XX XX` | `+262 262 XX XX XX` |
| Mobile (0692, 0693) | `0692 XX XX XX` | `+262 692 XX XX XX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+262262123456` | `+262 262 12 34 56` | `0262 12 34 56` | Réunion fixed — country code repeats as the internal area code |
| mobile | `+262692123456` | `+262 692 12 34 56` | `0692 12 34 56` | Mobile — the 0692/0693 ranges |

## Notes

- Réunion shares country code +262 with Mayotte; the two are separated by their internal prefixes (262/692 for Réunion, 269/639 for Mayotte).
- The French Southern and Antarctic Lands are also administratively attached to +262.
