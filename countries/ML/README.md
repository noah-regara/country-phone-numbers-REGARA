# Mali — Phone Number Formats

**ISO 3166-1:** `ML` / `MLI`  
**Country calling code:** +223  
**Trunk prefix:** none  
**International call prefix:** `00`  
**National significant number:** 8 digits

## Formatting

```
National:      XXXX XXXX
International: +223 XXXX XXXX
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Fixed line — SOTELMA (20, 21) | `20 XX XX XX` | `+223 20 XX XX XX` |
| Mobile — Malitel, Orange Mali (6X, 7X) | `6X XX XX XX` | `+223 6X XX XX XX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+22320201234` | `+223 2020 1234` | `2020 1234` | Bamako — SOTELMA fixed service on the 20 prefix |
| mobile | `+22365012345` | `+223 6501 2345` | `6501 2345` | Mobile — 6X and 7X GSM ranges |

## Notes

- Mali has no area codes; all calls use the full 8 digits.
- The plan was restructured in 2008 to accommodate growth.
