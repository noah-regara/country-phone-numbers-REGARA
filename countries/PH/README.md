# Philippines — Phone Number Formats

**ISO 3166-1:** `PH` / `PHL`  
**Country calling code:** +63  
**Trunk prefix:** `0`  
**International call prefix:** `00`  
**National significant number:** 9 or 10 digits

## Formatting

```
National:      0AA-XXX-XXXX (landline) / 09XX-XXX-XXXX (mobile)
International: +63 AA XXX XXXX (trunk 0 dropped)
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Metro Manila (2) — 8-digit subscriber numbers | `02-XXXX-XXXX` | `+63 2 XXXX XXXX` |
| Other areas (2–3 digit area codes) | `0XX-XXX-XXXX` | `+63 XX XXX XXXX` |
| Mobile (9XX) | `09XX-XXX-XXXX` | `+63 9XX XXX XXXX` |
| Toll-free | `1800-X-XXX-XXXX` | `+63 1800 X XXX XXXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+63281234567` | `+63 2 8123 4567` | `02-8123-4567` | Metro Manila — area code 2, expanded to 8-digit subscriber numbers in 2019 |
| fixed-line | `+63321234567` | `+63 32 123 4567` | `032-123-4567` | Cebu — area code 32 |
| mobile | `+639171234567` | `+63 917 123 4567` | `0917-123-4567` | Mobile — 0917 is a Globe Telecom range |

## Notes

- The Philippines uses an open plan: within the same area code the area code is normally omitted from landline-to-landline calls.
- Metro Manila landlines were expanded from 7 to 8 subscriber digits in 2019, so older 7-digit Manila numbers are no longer valid.
- All mobile numbers are 10 digits in NSN form and begin with 9.
