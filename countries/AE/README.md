# United Arab Emirates — Phone Number Formats

**ISO 3166-1:** `AE` / `ARE`  
**Country calling code:** +971  
**Trunk prefix:** `0`  
**International call prefix:** `00`  
**National significant number:** 8 or 9 digits

## Formatting

```
National:      0A XXX XXXX (landline) / 05X XXX XXXX (mobile)
International: +971 A XXX XXXX (trunk 0 dropped)
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Abu Dhabi (02), Dubai (04), Sharjah (06) | `04 XXX XXXX` | `+971 4 XXX XXXX` |
| Mobile (050, 052, 054, 055, 056, 058) | `050 XXX XXXX` | `+971 50 XXX XXXX` |
| Toll-free | `800 XXXX` | `+971 800 XXXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+97141234567` | `+971 4 123 4567` | `04 123 4567` | Dubai — area code 04 |
| fixed-line | `+97121234567` | `+971 2 123 4567` | `02 123 4567` | Abu Dhabi — area code 02 |
| mobile | `+971501234567` | `+971 50 123 4567` | `050 123 4567` | Mobile — 050/054/056 Etisalat, 052/055/058 du |

## Notes

- Landline subscriber numbers are 7 digits behind a single-digit emirate code, giving an 8-digit NSN; mobile NSNs are 9 digits.
- Each emirate has its own area code: 02 Abu Dhabi, 03 Al Ain, 04 Dubai, 06 Sharjah/Ajman/Umm Al Quwain, 07 Ras Al Khaimah, 09 Fujairah.
