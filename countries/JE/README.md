# Jersey — Phone Number Formats

**ISO 3166-1:** `JE` / `JEY`  
**Country calling code:** +44  
**Trunk prefix:** `0`  
**International call prefix:** `00`  
**National significant number:** 10 digits

## Formatting

```
National:      01534 XXXXXX
International: +44 1534 XXXXXX (trunk 0 dropped)
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Fixed line | `01534 XXXXXX` | `+44 1534 XXXXXX` |
| Mobile (Jersey-allocated 07 ranges) | `07797 XXXXXX` | `+44 7797 XXXXXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+441534123456` | `+44 1534 123456` | `01534 123456` | Jersey — area code 01534 |
| mobile | `+447797123456` | `+44 7797 123456` | `07797 123456` | Mobile — 077977–077979 are Jersey-allocated ranges |

## Notes

- Jersey is a Crown Dependency, not part of the UK, but shares the +44 country code and the UK numbering plan.
- All Jersey landlines sit under the single area code 01534.
- Jersey mobile ranges (e.g. 074572, 075090–075097, 077003, 077977–077979, 079370–079379) are separately allocated and are frequently excluded from UK mobile call allowances.
