# Bangladesh — Phone Number Formats

**ISO 3166-1:** `BD` / `BGD`  
**Country calling code:** +880  
**Trunk prefix:** `0`  
**International call prefix:** `00`  
**National significant number:** variable

## Formatting

```
National:      0A-XXXXXXXX (landline) / 01XXX-XXXXXX (mobile)
International: +880 A XXXXXXXX (trunk 0 dropped)
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Dhaka (2) | `02-XXXXXXXX` | `+880 2 XXXXXXXX` |
| Other districts (2–4 digit area codes) | `0XXX-XXXXXX` | `+880 XXX XXXXXX` |
| Mobile (013, 014, 015, 016, 017, 018, 019) | `01XXX-XXXXXX` | `+880 1XXX XXXXXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+880212345678` | `+880 2 1234 5678` | `02-12345678` | Dhaka — area code 2, operated by BTCL |
| mobile | `+8801712345678` | `+880 1712 345678` | `01712-345678` | Mobile — 017 and 013 are Grameenphone ranges |
| mobile | `+8801812345678` | `+880 1812 345678` | `01812-345678` | Mobile — 018 is a Robi Axiata range |

## Notes

- All Bangladeshi mobile numbers begin with 01; the following two digits identify the original operator (013/017 Grameenphone, 014/019 Banglalink, 018 Robi Axiata, 015 Teletalk, 016 Airtel).
- Landline area codes are 2–4 digits with variable subscriber lengths, so NSN length varies.
- The national numbering plan was last revised on 2017-07-31.
