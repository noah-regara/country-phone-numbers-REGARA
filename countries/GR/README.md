# Greece — Phone Number Formats

**ISO 3166-1:** `GR` / `GRC`  
**Country calling code:** +30  
**Trunk prefix:** none  
**International call prefix:** `00`  
**National significant number:** 10 digits

## Formatting

```
National:      XXX XXX XXXX (closed 10-digit plan, no trunk prefix)
International: +30 XXX XXX XXXX
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Athens (21x) | `210 XXX XXXX` | `+30 210 XXX XXXX` |
| Thessaloniki (231x) | `2310 XXX XXX` | `+30 2310 XXX XXX` |
| Mobile (69x) | `694 XXX XXXX` | `+30 694 XXX XXXX` |
| Freephone | `800 XXX XXXX` | `+30 800 XXX XXXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+302101234567` | `+30 210 123 4567` | `210 123 4567` | Athens — area code 21, the 0 that follows is part of the subscriber block |
| fixed-line | `+302310123456` | `+30 2310 123 456` | `2310 123 456` | Thessaloniki — area code 2310 |
| mobile | `+306941234567` | `+30 694 123 4567` | `694 123 4567` | Mobile — all Greek mobiles begin 69 |
| toll-free | `+308001234567` | `+30 800 123 4567` | `800 123 4567` | Freephone |

## Notes

- Greece moved to a closed 10-digit plan in 2001–2002; there is no trunk prefix and the full number is dialled for every call.
- All geographic numbers begin with 2 and all mobile numbers with 69.
- Area codes are 2–4 digits and the subscriber number shrinks to keep the total at 10.
