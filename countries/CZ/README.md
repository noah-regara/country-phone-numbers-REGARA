# Czechia — Phone Number Formats

**ISO 3166-1:** `CZ` / `CZE`  
**Country calling code:** +420  
**Trunk prefix:** none  
**International call prefix:** `00`  
**National significant number:** 9 digits

## Formatting

```
National:      XXX XXX XXX (closed plan, no trunk prefix)
International: +420 XXX XXX XXX
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Prague (2xx) | `2XX XXX XXX` | `+420 2XX XXX XXX` |
| Other geographic (3xx–5xx) | `5XX XXX XXX` | `+420 5XX XXX XXX` |
| Mobile (6xx, 7xx) | `6XX XXX XXX` | `+420 6XX XXX XXX` |
| Freephone (zelená linka) | `800 XXX XXX` | `+420 800 XXX XXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+420224123456` | `+420 224 123 456` | `224 123 456` | Prague — geographic numbers there begin with 2 |
| fixed-line | `+420541123456` | `+420 541 123 456` | `541 123 456` | Brno — 5xx range |
| mobile | `+420602123456` | `+420 602 123 456` | `602 123 456` | Mobile — 602 is an O2 Czech Republic range |
| toll-free | `+420800123456` | `+420 800 123 456` | `800 123 456` | Zelená linka (freephone) |

## Notes

- Czechia adopted a closed 9-digit plan on 2002-09-22 and dropped the trunk prefix 0; the full number is dialled for every call.
- Numbers are conventionally grouped in threes.
