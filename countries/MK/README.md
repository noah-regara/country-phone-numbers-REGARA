# North Macedonia — Phone Number Formats

**ISO 3166-1:** `MK` / `MKD`  
**Country calling code:** +389  
**Trunk prefix:** `0`  
**International call prefix:** `00`  
**National significant number:** 8 digits

## Formatting

```
National:      0A XXX XXXX (Skopje) / 0AA XXX XXX (elsewhere)
International: +389 A XXX XXXX (trunk 0 dropped)
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Skopje (02) | `02 XXX XXXX` | `+389 2 XXX XXXX` |
| Other geographic (031–047) | `0XX XXX XXX` | `+389 XX XXX XXX` |
| Mobile (070–078) | `070 XXX XXX` | `+389 70 XXX XXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+38921234567` | `+389 2 123 4567` | `02 123 4567` | Skopje — single-digit area code 2 |
| fixed-line | `+38946123456` | `+389 46 123 456` | `046 123 456` | Ohrid — area code 046 |
| mobile | `+38970123456` | `+389 70 123 456` | `070 123 456` | Mobile — 070–072 Makedonski Telekom, 075–078 A1 |

## Notes

- Closed 8-digit plan. The area code must always be dialled domestically because many fixed and mobile operators share the plan.
- Skopje uses the single-digit area code 2; other regions use two digits.
