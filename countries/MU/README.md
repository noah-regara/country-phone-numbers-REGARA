# Mauritius — Phone Number Formats

**ISO 3166-1:** `MU` / `MUS`  
**Country calling code:** +230  
**Trunk prefix:** none  
**International call prefix:** `00`  
**National significant number:** 7 or 8 digits

## Formatting

```
National:      XXX XXXX (fixed) / 5XXX XXXX (mobile)
International: +230 XXX XXXX
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Fixed line — north (2), centre (4), south (6) | `4XX XXXX` | `+230 4XX XXXX` |
| Mobile (5, 7) | `5XXX XXXX` | `+230 5XXX XXXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+2304123456` | `+230 412 3456` | `412 3456` | Central region — fixed prefix 4 |
| mobile | `+23051234567` | `+230 5123 4567` | `5123 4567` | Mobile — 5 prefix; mobile numbers are one digit longer than fixed |
| fixed-line | `+2302123456` | `+230 212 3456` | `212 3456` | Northern region — fixed prefix 2 |

## Notes

- Closed plan with no trunk prefix or area codes. Fixed numbers are 7 digits, mobile numbers 8.
- The leading digit of a fixed number indicates the region: 2 north, 4 centre, 6 south.
