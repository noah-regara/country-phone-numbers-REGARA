# Switzerland — Phone Number Formats

**ISO 3166-1:** `CH` / `CHE`  
**Country calling code:** +41  
**Trunk prefix:** `0`  
**International call prefix:** `00`  
**National significant number:** 9 digits

## Formatting

```
National:      0AA XXX XX XX (closed plan, area code always dialled)
International: +41 AA XXX XX XX (trunk 0 dropped)
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Zurich (044/043) | `044 XXX XX XX` | `+41 44 XXX XX XX` |
| Bern (031), Geneva (022), Basel (061) | `031 XXX XX XX` | `+41 31 XXX XX XX` |
| Mobile | `07X XXX XX XX` | `+41 7X XXX XX XX` |
| Freephone | `0800 XXX XXX` | `+41 800 XXX XXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+41441234567` | `+41 44 123 45 67` | `044 123 45 67` | Zurich — area code 044 |
| fixed-line | `+41311234567` | `+41 31 123 45 67` | `031 123 45 67` | Bern — area code 031 |
| mobile | `+41791234567` | `+41 79 123 45 67` | `079 123 45 67` | Mobile — 079 is a Swisscom range |
| toll-free | `+41800123456` | `+41 800 123 456` | `0800 123 456` | Gratisnummer / numéro gratuit |

## Notes

- Switzerland runs a closed plan: the full 10-digit national form (0 + 9-digit NSN) is dialled for every call, including local ones.
- Liechtenstein (+423) is a separate country code but is closely integrated with the Swiss network.
