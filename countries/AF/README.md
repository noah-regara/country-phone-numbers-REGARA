# Afghanistan — Phone Number Formats

**ISO 3166-1:** `AF` / `AFG`  
**Country calling code:** +93  
**Trunk prefix:** `0`  
**International call prefix:** `00`  
**National significant number:** 9 digits

## Formatting

```
National:      0AA XXX XXXX
International: +93 AA XXX XXXX (trunk 0 dropped)
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Kabul (020) | `020 XXX XXXX` | `+93 20 XXX XXXX` |
| Other provinces (2-digit area codes) | `0XX XXX XXXX` | `+93 XX XXX XXXX` |
| Mobile — AWCC (070, 071), Roshan (079, 072), Etisalat (078), MTN (077) | `070 XXX XXXX` | `+93 70 XXX XXXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+93201234567` | `+93 20 123 4567` | `020 123 4567` | Kabul — area code 020 |
| mobile | `+93701234567` | `+93 70 123 4567` | `070 123 4567` | Mobile — 070 is an AWCC range |
| mobile | `+93791234567` | `+93 79 123 4567` | `079 123 4567` | Mobile — 079 is a Roshan range |

## Notes

- Closed 9-digit plan; all area codes are two digits after the trunk 0.
- Mobile prefixes identify the operator: 070/071 AWCC, 072/079 Roshan, 077 MTN, 078 Etisalat.
