# Suriname — Phone Number Formats

**ISO 3166-1:** `SR` / `SUR`  
**Country calling code:** +597  
**Trunk prefix:** none  
**International call prefix:** `00`  
**National significant number:** 6 or 7 digits

## Formatting

```
National:      XXX XXX (fixed) / XXX XXXX (mobile)
International: +597 XXX XXX
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Paramaribo fixed (4xxxxx) | `4XXXXX` | `+597 4XXXXX` |
| Other geographic (21–37) | `XXXXXX` | `+597 XXXXXX` |
| Mobile (71–89) | `71XXXXX` | `+597 71XXXXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+597412345` | `+597 412 345` | `412345` | Paramaribo — the 4 prefix marks Telesur geographic numbers |
| mobile | `+5977112345` | `+597 711 2345` | `7112345` | Mobile — 71 is a Digicel Suriname range; mobile numbers are 7 digits |

## Notes

- Fixed NSNs are 6 digits and mobile NSNs 7, so length distinguishes the two.
- Geographic codes 21–37 cover the districts; 56, 68 and 71–89 are non-geographic (VoIP, wireless local loop, mobile).
