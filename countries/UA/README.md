# Ukraine — Phone Number Formats

**ISO 3166-1:** `UA` / `UKR`  
**Country calling code:** +380  
**Trunk prefix:** `0`  
**International call prefix:** `00`  
**National significant number:** 9 digits

## Formatting

```
National:      0AA XXX XX XX
International: +380 AA XXX XX XX (trunk 0 dropped)
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Kyiv (044) | `044 XXX XX XX` | `+380 44 XXX XX XX` |
| Other geographic (2–4 digit area codes) | `032 XXX XX XX` | `+380 32 XXX XX XX` |
| Mobile (039, 050, 06x, 09x) | `067 XXX XX XX` | `+380 67 XXX XX XX` |
| Freephone | `0800 XXX XXX` | `+380 800 XXX XXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+380441234567` | `+380 44 123 45 67` | `044 123 45 67` | Kyiv — area code 44 |
| fixed-line | `+380321234567` | `+380 32 123 45 67` | `032 123 45 67` | Lviv — area code 32 |
| mobile | `+380671234567` | `+380 67 123 45 67` | `067 123 45 67` | Mobile — 067 is a Kyivstar range |
| toll-free | `+380800123456` | `+380 800 123 456` | `0800 123 456` | Freephone |

## Notes

- Ukraine switched to EU-style numbering conventions on 2009-10-14, replacing the Soviet-era trunk prefix 8 with 0.
- NSNs are 9 digits; area codes are 2–4 digits with the subscriber number shrinking to match.
