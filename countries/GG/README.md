# Guernsey — Phone Number Formats

**ISO 3166-1:** `GG` / `GGY`  
**Country calling code:** +44  
**Trunk prefix:** `0`  
**International call prefix:** `00`  
**National significant number:** 10 digits

## Formatting

```
National:      01481 XXXXXX
International: +44 1481 XXXXXX (trunk 0 dropped)
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Fixed line (Guernsey, Alderney, Sark) | `01481 XXXXXX` | `+44 1481 XXXXXX` |
| Mobile (Guernsey-allocated 07 ranges) | `07781 XXXXXX` | `+44 7781 XXXXXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+441481123456` | `+44 1481 123456` | `01481 123456` | Guernsey — area code 01481, also covering Alderney and Sark |
| mobile | `+447781123456` | `+44 7781 123456` | `07781 123456` | Mobile — 077810–077819 are Guernsey-allocated ranges |

## Notes

- Guernsey is a Crown Dependency sharing the +44 country code and UK numbering plan.
- The Bailiwick of Guernsey — including Alderney and Sark — uses the single area code 01481.
- Guernsey mobile ranges include 077810–077819, 078391/078392, 078397/078398, 079111 and 079117.
