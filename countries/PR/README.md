# Puerto Rico — Phone Number Formats

**ISO 3166-1:** `PR` / `PRI`  
**Country calling code:** +1  
**Area codes:** `787`, `939`  
**Trunk prefix:** `1`  
**International call prefix:** `011`  
**National significant number:** 10 digits

## Formatting

```
National:      (NPA) NXX-XXXX
International: +1 NPA NXX XXXX
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Geographic (fixed or mobile) | `(NPA) NXX-XXXX` | `+1 NPA NXX XXXX` |
| Toll-free (shared NANP-wide) | `(800) NXX-XXXX` | `+1 800 NXX XXXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+17877211234` | `+1 787 721 1234` | `(787) 721-1234` | San Juan — 787 is the original Puerto Rico area code |
| fixed-line | `+19395551234` | `+1 939 555 1234` | `(939) 555-1234` | Puerto Rico — 939 is the overlay area code added in 2001 |

## Notes

- Part of the North American Numbering Plan: country code +1, a 10-digit NSN written NPA-NXX-XXXX.
- NPA is the 3-digit area code, NXX the 3-digit central office code; both begin with a digit 2–9. The final four digits are the line number.
- The domestic long-distance prefix is 1 and the international call prefix is 011.
- Puerto Rico uses two overlaid area codes, 787 and 939; ten-digit dialling is mandatory.
