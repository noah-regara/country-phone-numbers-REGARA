# Macao — Phone Number Formats

**ISO 3166-1:** `MO` / `MAC`  
**Country calling code:** +853  
**Trunk prefix:** none  
**International call prefix:** `00`  
**National significant number:** 8 digits

## Formatting

```
National:      XXXX XXXX
International: +853 XXXX XXXX
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Fixed line, residential/business (28) | `28XX XXXX` | `+853 28XX XXXX` |
| Fixed line, business/government (8) | `8XXX XXXX` | `+853 8XXX XXXX` |
| Mobile (6) | `6XXX XXXX` | `+853 6XXX XXXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+85328123456` | `+853 2812 3456` | `2812 3456` | Fixed line — 28 is the main residential and business prefix |
| fixed-line | `+85388123456` | `+853 8812 3456` | `8812 3456` | Fixed line — 8 prefix used by government and corporate lines |
| mobile | `+85366123456` | `+853 6612 3456` | `6612 3456` | Mobile — all Macau mobiles begin with 6 |

## Notes

- Macau has no area codes or trunk prefix; all numbers are 8 digits.
- Macau keeps its own country code +853, separate from both mainland China (+86) and Hong Kong (+852).
