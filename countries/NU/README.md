# Niue — Phone Number Formats

**ISO 3166-1:** `NU` / `NIU`  
**Country calling code:** +683  
**Trunk prefix:** none  
**International call prefix:** `00`  
**National significant number:** 4 or 7 digits

## Formatting

```
National:      XXXX
International: +683 XXXX
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Postpaid PSTN (4000–4999, 7000–9999) | `4XXX` | `+683 4XXX` |
| Prepaid GSM mobile (5000–5999, 6000–6999) | `5XXX` | `+683 5XXX` |
| Prepaid LTE mobile (8884000–8889999) | `888XXXX` | `+683 888XXXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+6834747` | `+683 4747` | `4747` | Postpaid PSTN — the 4000–4999 range |
| mobile | `+6835123` | `+683 5123` | `5123` | Prepaid GSM mobile — the 5000–5999 range |
| mobile | `+6838884000` | `+683 888 4000` | `8884000` | Prepaid LTE mobile — the 7-digit 8884000–8889999 range |

## Notes

- Niue has one of the shortest numbering plans in the world: most numbers are just 4 digits.
- An updated ITU-registered plan took effect on 2018-05-01, adding a 7-digit LTE mobile range alongside the 4-digit numbers.
- Telecom Niue is the sole provider.
