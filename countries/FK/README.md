# Falkland Islands (Malvinas) — Phone Number Formats

**ISO 3166-1:** `FK` / `FLK`  
**Country calling code:** +500  
**Trunk prefix:** none  
**International call prefix:** `00`  
**National significant number:** 5 digits

## Formatting

```
National:      XXXXX
International: +500 XXXXX
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Fixed line (2XXXX, 3XXXX, 4XXXX, 7XXXX) | `2XXXX` | `+500 2XXXX` |
| Mobile (5XXXX, 6XXXX) | `5XXXX` | `+500 5XXXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+50021234` | `+500 21234` | `21234` | Stanley — PSTN range |
| mobile | `+50051234` | `+500 51234` | `51234` | Mobile — GSM range 5XXXX |

## Notes

- The Falkland Islands use a short 5-digit NSN with no trunk prefix or area codes.
- South Georgia and the South Sandwich Islands share the +500 code.
