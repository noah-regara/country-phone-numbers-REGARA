# Costa Rica — Phone Number Formats

**ISO 3166-1:** `CR` / `CRI`  
**Country calling code:** +506  
**Trunk prefix:** none  
**International call prefix:** `00`  
**National significant number:** 8 digits

## Formatting

```
National:      XXXX-XXXX
International: +506 XXXX XXXX
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Fixed line (2) | `2XXX-XXXX` | `+506 2XXX XXXX` |
| Mobile (6, 7, 8) | `8XXX-XXXX` | `+506 8XXX XXXX` |
| Toll-free | `800-XXX-XXXX` | `+506 800 XXX XXXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+50622221234` | `+506 2222 1234` | `2222-1234` | San José — the 2 prefix marks all Costa Rican landlines |
| mobile | `+50687654321` | `+506 8765 4321` | `8765-4321` | Mobile — 8 prefix (also 6 and 7) |

## Notes

- On 2008-03-20 Costa Rica moved from 7 to 8 digits by prefixing 2 to every landline and 8 to every mobile number.
- No area codes or trunk prefix; the leading digit distinguishes fixed from mobile.
