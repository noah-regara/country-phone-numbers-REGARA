# Iran, Islamic Republic of — Phone Number Formats

**ISO 3166-1:** `IR` / `IRN`  
**Country calling code:** +98  
**Trunk prefix:** `0`  
**International call prefix:** `00`  
**National significant number:** 10 digits

## Formatting

```
National:      0AA XXXX XXXX (landline) / 09XX XXX XXXX (mobile)
International: +98 AA XXXX XXXX (trunk 0 dropped)
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Tehran (021) | `021 XXXX XXXX` | `+98 21 XXXX XXXX` |
| Other provinces (2-digit area codes, e.g. Mashhad 051, Isfahan 031) | `0XX XXXX XXXX` | `+98 XX XXXX XXXX` |
| Mobile (091X IR-MCI, 093X Irancell, 092X RighTel) | `0910 123 4567` | `+98 910 123 4567` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+982112345678` | `+98 21 1234 5678` | `021 1234 5678` | Tehran — area code 21 |
| fixed-line | `+985112345678` | `+98 51 1234 5678` | `051 1234 5678` | Mashhad — area code 51 |
| mobile | `+989101234567` | `+98 910 123 4567` | `0910 123 4567` | Mobile — 091X is an IR-MCI (Hamrah-e Avval) range |

## Notes

- Closed 10-digit plan: 11 digits including the trunk 0.
- All mobile numbers begin 09, making them easy to distinguish from geographic ranges.
