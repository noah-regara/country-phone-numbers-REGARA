# Andorra — Phone Number Formats

**ISO 3166-1:** `AD` / `AND`  
**Country calling code:** +376  
**Trunk prefix:** none  
**International call prefix:** `00`  
**National significant number:** 6 digits

## Formatting

```
National:      XXX XXX
International: +376 XXX XXX
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Fixed line (7xxxxx, 8xxxxx) | `8XX XXX` | `+376 8XX XXX` |
| Mobile (3xxxxx, 6xxxxx) | `3XX XXX` | `+376 3XX XXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+376812345` | `+376 812 345` | `812 345` | Fixed line — 7 and 8 ranges |
| mobile | `+376312345` | `+376 312 345` | `312 345` | Mobile — 3 and 6 ranges |

## Notes

- Andorra took its own country code +376 on 1994-12-17; it was previously reachable through France (prefix 628) and Spain (area code 9738).
- All numbers are 6 digits with no trunk prefix or area codes.
