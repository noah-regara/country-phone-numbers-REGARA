# Portugal — Phone Number Formats

**ISO 3166-1:** `PT` / `PRT`  
**Country calling code:** +351  
**Trunk prefix:** none  
**International call prefix:** `00`  
**National significant number:** 9 digits

## Formatting

```
National:      XXX XXX XXX (closed plan, no trunk prefix)
International: +351 XXX XXX XXX
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Lisbon (21), Porto (22) | `21 XXX XXXX` | `+351 21 XXX XXXX` |
| Other geographic | `2XX XXX XXX` | `+351 2XX XXX XXX` |
| Mobile | `9X XXX XXXX` | `+351 9X XXX XXXX` |
| Freephone | `800 XXX XXX` | `+351 800 XXX XXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+351213456789` | `+351 21 345 6789` | `21 345 6789` | Lisbon — geographic code 21 |
| fixed-line | `+351223456789` | `+351 22 345 6789` | `22 345 6789` | Porto — geographic code 22 |
| mobile | `+351912345678` | `+351 91 234 5678` | `91 234 5678` | Mobile — 91/92/93/96; the second digit identifies the original operator |
| toll-free | `+351800123456` | `+351 800 123 456` | `800 123 456` | Número verde |

## Notes

- Portugal dropped the trunk prefix 0 on 1999-10-31 and moved to a closed 9-digit plan; the full number is dialled for every call.
- Geographic numbers begin with 2, mobile numbers with 9.
