# Moldova, Republic of — Phone Number Formats

**ISO 3166-1:** `MD` / `MDA`  
**Country calling code:** +373  
**Trunk prefix:** `0`  
**International call prefix:** `00`  
**National significant number:** 8 digits

## Formatting

```
National:      0AA XXX XXX
International: +373 AA XXX XXX (trunk 0 dropped)
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Chișinău (022) | `022 XXX XXX` | `+373 22 XXX XXX` |
| Other geographic (2XX) | `0XXX XX XXX` | `+373 XXX XX XXX` |
| Mobile (6XX, 7XX) | `069 XXX XXX` | `+373 69 XXX XXX` |
| Freephone (8XX) | `0800 XXXXX` | `+373 800 XXXXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+37322123456` | `+373 22 123 456` | `022 123 456` | Chișinău — area code 22 |
| mobile | `+37369123456` | `+373 69 123 456` | `069 123 456` | Mobile — 6XX and 7XX are non-geographic mobile ranges |
| toll-free | `+37380012345` | `+373 800 12345` | `0800 12345` | Freephone |

## Notes

- Moldova adopted its current closed 8-digit plan on 2004-02-01 and took country code +373 in 1993.
- Leading digits encode service type: 2XX fixed/geographic, 6XX and 7XX mobile, 8XX freephone, 9XX premium.
