# Ethiopia — Phone Number Formats

**ISO 3166-1:** `ET` / `ETH`  
**Country calling code:** +251  
**Trunk prefix:** `0`  
**International call prefix:** `00`  
**National significant number:** 9 digits

## Formatting

```
National:      0AA XXX XXXX
International: +251 AA XXX XXXX (trunk 0 dropped)
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Addis Ababa (011) | `011 XXX XXXX` | `+251 11 XXX XXXX` |
| Regional (area codes 22–58) | `0XX XXX XXXX` | `+251 XX XXX XXXX` |
| Mobile — Ethio telecom (09X) | `091 XXX XXXX` | `+251 91 XXX XXXX` |
| Mobile — Safaricom Ethiopia (07X) | `070 XXX XXXX` | `+251 70 XXX XXXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+251111112345` | `+251 11 111 2345` | `011 111 2345` | Addis Ababa — area code 11 |
| mobile | `+251911234567` | `+251 91 123 4567` | `091 123 4567` | Mobile — 9X denotes Ethio telecom |
| mobile | `+251701234567` | `+251 70 123 4567` | `070 123 4567` | Mobile — 7X denotes Safaricom Ethiopia |

## Notes

- Closed 9-digit plan; area codes were revised in 2005 with Addis Ababa on 11 and regional codes running 22–58.
- The first digit of a mobile number identifies the operator: 9 Ethio telecom, 7 Safaricom Ethiopia.
