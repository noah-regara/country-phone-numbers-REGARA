# Samoa — Phone Number Formats

**ISO 3166-1:** `WS` / `WSM`  
**Country calling code:** +685  
**Trunk prefix:** none  
**International call prefix:** `0`  
**National significant number:** variable

## Formatting

```
National:      XX XXX / XXX XXXX (variable)
International: +685 XX XXX
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Fixed line (2–6) | `20 XXX` | `+685 20 XXX` |
| Mobile (7X, 83–87, 89) | `72 XX XXX` | `+685 72 XX XXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+68520123` | `+685 20 123` | `20 123` | Apia — 5-digit fixed line in the 2x range |
| mobile | `+6857201234` | `+685 7201 234` | `7201 234` | Mobile — 7x ranges, 7 digits |

## Notes

- Samoa has a genuinely variable plan: NSNs run from about 3 to 7 digits depending on the service, so length cannot validate a Samoan number.
- Numbers beginning 2–6 are mainly fixed; 7, 83–87 and 89 are cellular and special services.
