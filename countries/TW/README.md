# Taiwan, Province of China — Phone Number Formats

**ISO 3166-1:** `TW` / `TWN`  
**Country calling code:** +886  
**Trunk prefix:** `0`  
**International call prefix:** `002 (also 005, 006, 007, 009)`  
**National significant number:** 8 or 9 digits

## Formatting

```
National:      0A-XXXX-XXXX (landline) / 09XX-XXX-XXX (mobile)
International: +886 A XXXX XXXX (trunk 0 dropped)
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Taipei / New Taipei / Keelung (02) | `02-XXXX-XXXX` | `+886 2 XXXX XXXX` |
| Other areas (03 Taoyuan, 04 Taichung, 07 Kaohsiung) | `04-XXXX-XXXX` | `+886 4 XXXX XXXX` |
| Mobile (09X) | `09XX-XXX-XXX` | `+886 9XX XXX XXX` |
| Toll-free | `0800-XXX-XXX` | `+886 800 XXX XXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+886223456789` | `+886 2 2345 6789` | `02-2345-6789` | Taipei — area code 02 covers Taipei City, New Taipei City and Keelung |
| fixed-line | `+886412345678` | `+886 4 1234 5678` | `04-1234-5678` | Taichung — area code 04 |
| mobile | `+886912345678` | `+886 912 345 678` | `0912-345-678` | Mobile — all Taiwanese mobiles begin 09 and work nationwide |
| toll-free | `+886800111222` | `+886 800 111 222` | `0800-111-222` | Toll-free — 0800 and 0809 prefixes |

## Notes

- The international access prefix varies by carrier (002, 005, 006, 007, 009), each billed differently.
- Area codes are 1–2 digits after the trunk 0; Taipei is 2.
