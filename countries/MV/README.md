# Maldives — Phone Number Formats

**ISO 3166-1:** `MV` / `MDV`  
**Country calling code:** +960  
**Trunk prefix:** none  
**International call prefix:** `00`  
**National significant number:** 7 digits

## Formatting

```
National:      XXX XXXX
International: +960 XXX XXXX
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Fixed line — Malé (330, 331, 332…) | `33X XXXX` | `+960 33X XXXX` |
| Mobile — Dhiraagu (77, 79), Ooredoo (75, 76) | `77X XXXX` | `+960 77X XXXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+9603301234` | `+960 330 1234` | `330 1234` | Malé City — the 330 fixed block |
| mobile | `+9607712345` | `+960 771 2345` | `771 2345` | Mobile — 77 is a Dhiraagu range |

## Notes

- The current 7-digit closed plan was introduced in 2005.
- Fixed ranges are organised by atoll and city; mobile ranges by carrier.
