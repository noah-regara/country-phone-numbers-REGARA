# Vanuatu — Phone Number Formats

**ISO 3166-1:** `VU` / `VUT`  
**Country calling code:** +678  
**Trunk prefix:** none  
**International call prefix:** `00`  
**National significant number:** variable

## Formatting

```
National:      XX XXX (fixed) / XX XXXXX (mobile)
International: +678 XX XXX
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Fixed line (2X — Telecom Vanuatu) | `20 XXXX` | `+678 20 XXXX` |
| Mobile (5X, 7X — Telecom Vanuatu, Digicel) | `70 XXXXX` | `+678 70 XXXXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+67820123` | `+678 20 123` | `20 123` | Fixed line — 5 digits; the 20xxx and 22–29xxx ranges are Telecom Vanuatu |
| mobile | `+6787012345` | `+678 70 12345` | `70 12345` | Mobile — 7x ranges; mobile numbers are one digit longer than fixed |

## Notes

- Vanuatu NSNs vary from 5 to 7 digits by service, so length is not a reliable validator.
- National destination codes are allocated per operator (Telecom Vanuatu, Digicel Vanuatu).
