# Comoros — Phone Number Formats

**ISO 3166-1:** `KM` / `COM`  
**Country calling code:** +269  
**Trunk prefix:** none  
**International call prefix:** `00`  
**National significant number:** 7 digits

## Formatting

```
National:      XXX XXXX
International: +269 XXX XXXX
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Fixed line — Moroni, Mutsamudu, Domoni, Mohéli (760–779) | `773 XXXX` | `+269 773 XXXX` |
| Mobile — Comores Telecom, Telma (32X, 33X, 34X) | `32X XXXX` | `+269 32X XXXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+2697731234` | `+269 773 1234` | `773 1234` | Moroni — the 773 geographic prefix |
| mobile | `+2693212345` | `+269 321 2345` | `321 2345` | Mobile — the 32/33/34 non-geographic ranges |

## Notes

- Closed 7-digit plan with no trunk prefix.
- Mayotte, geographically part of the Comoros archipelago, is a French department and left +269 for +262 in 2007.
