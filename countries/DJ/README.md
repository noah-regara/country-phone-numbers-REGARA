# Djibouti — Phone Number Formats

**ISO 3166-1:** `DJ` / `DJI`  
**Country calling code:** +253  
**Trunk prefix:** none  
**International call prefix:** `00`  
**National significant number:** 8 digits

## Formatting

```
National:      XX XX XX XX
International: +253 XX XX XX XX
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Fixed line — Djibouti City (21) | `21 XX XX XX` | `+253 21 XX XX XX` |
| Mobile — Djibouti Telecom (77) | `77 XX XX XX` | `+253 77 XX XX XX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+25321123456` | `+253 21 12 34 56` | `21 12 34 56` | Djibouti City and Balbala — the 21 fixed range |
| mobile | `+25377123456` | `+253 77 12 34 56` | `77 12 34 56` | Mobile — the 77 GSM range (Djibouti Telecom) |

## Notes

- The first two digits define the service type and the next two the locality for fixed lines.
- Closed 8-digit plan with no trunk prefix; numbers are written in pairs.
