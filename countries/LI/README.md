# Liechtenstein — Phone Number Formats

**ISO 3166-1:** `LI` / `LIE`  
**Country calling code:** +423  
**Trunk prefix:** none  
**International call prefix:** `00`  
**National significant number:** 7 digits

## Formatting

```
National:      XXX XX XX
International: +423 XXX XX XX
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Fixed line (2xx xxxx) | `2XX XX XX` | `+423 2XX XX XX` |
| Mobile (7xx xxxx) | `7XX XX XX` | `+423 7XX XX XX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+4232371234` | `+423 237 12 34` | `237 12 34` | Vaduz — fixed lines begin with 2 |
| mobile | `+4237871234` | `+423 787 12 34` | `787 12 34` | Mobile — 7xx ranges |

## Notes

- Liechtenstein adopted its own country code +423 on 1999-04-05; it was previously reached as +41 75 through the Swiss numbering plan.
- Calls from Switzerland now require international dialling (00423), despite the close integration of the two networks.
- All numbers are 7 digits with no trunk prefix or area codes.
