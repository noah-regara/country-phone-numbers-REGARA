# Pitcairn — Phone Number Formats

**ISO 3166-1:** `PN` / `PCN`  
**Country calling code:** +64  
**Trunk prefix:** `0`  
**International call prefix:** `00`  
**National significant number:** variable

## Formatting

```
National:      no local numbering plan
International: reached via +64 (New Zealand) or satellite
```

## Examples

_No public numbering is assigned to this territory — see the notes below._

## Notes

- Pitcairn has no numbering plan of its own and no local exchange. With a population of a few dozen, the island is served by satellite.
- Contact numbers for the Pitcairn Islands administration are New Zealand +64 numbers, and the island itself has historically been reached over Inmarsat satellite numbers in the +872 range.
- ISO 3166-1 assigns PN, but no country calling code is allocated to the territory.
