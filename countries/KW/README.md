# Kuwait — Phone Number Formats

**ISO 3166-1:** `KW` / `KWT`  
**Country calling code:** +965  
**Trunk prefix:** none  
**International call prefix:** `00`  
**National significant number:** 8 digits

## Formatting

```
National:      XXXX XXXX
International: +965 XXXX XXXX
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Fixed line (2) | `2XXX XXXX` | `+965 2XXX XXXX` |
| Mobile — STC (5), Ooredoo (6), Zain (9) | `5XXX XXXX` | `+965 5XXX XXXX` |
| Toll-free | `800 XXXX` | `+965 800 XXXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+96522401234` | `+965 2240 1234` | `2240 1234` | Fixed line — all Kuwaiti landlines begin with 2 |
| mobile | `+96551234567` | `+965 5123 4567` | `5123 4567` | Mobile — 5 denotes STC Kuwait |
| mobile | `+96591234567` | `+965 9123 4567` | `9123 4567` | Mobile — 9 denotes Zain |

## Notes

- Kuwait moved to 8-digit numbers in October 2008 by prefixing a service digit to all fixed and mobile numbers.
- No trunk prefix or area codes; the leading digit identifies service and operator (2 fixed, 5 STC, 6 Ooredoo, 9 Zain).
