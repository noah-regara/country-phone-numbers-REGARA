# Tajikistan — Phone Number Formats

**ISO 3166-1:** `TJ` / `TJK`  
**Country calling code:** +992  
**Trunk prefix:** `8`  
**International call prefix:** `810`  
**National significant number:** variable

## Formatting

```
National:      8 AAA XXXXXX (variable area-code length)
International: +992 AAA XXXXXX
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Dushanbe (372) | `8 372 XXXXXX` | `+992 372 XXXXXX` |
| Other regions (2–6 digit area codes) | `8 XXXX XXXX` | `+992 XXXX XXXX` |
| Mobile (5X, 9X) | `8 55 XXX XXXX` | `+992 55 XXX XXXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+992372123456` | `+992 372 123456` | `8 372 123456` | Dushanbe — 3-digit area code 372 |
| mobile | `+992551234567` | `+992 55 123 4567` | `8 55 123 4567` | Mobile — 5X range |

## Notes

- Tajikistan retains the Soviet-era trunk prefix 8 and the 8~10 international access sequence.
- Area codes run from 2 to 6 digits and NSN length varies from about 4 to 9, so length-based validation is unreliable.
