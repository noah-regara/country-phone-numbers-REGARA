# Israel — Phone Number Formats

**ISO 3166-1:** `IL` / `ISR`  
**Country calling code:** +972  
**Trunk prefix:** `0`  
**International call prefix:** `00 (also carrier codes 012, 013, 014, 018)`  
**National significant number:** 8 or 9 digits

## Formatting

```
National:      0A-XXX-XXXX (landline) / 05X-XXX-XXXX (mobile)
International: +972 A XXX XXXX (trunk 0 dropped)
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Tel Aviv and Central District (03) | `03-XXX-XXXX` | `+972 3 XXX XXXX` |
| Jerusalem (02), Haifa (04), South (08), Sharon (09) | `02-XXX-XXXX` | `+972 2 XXX XXXX` |
| Mobile (050–059) | `050-XXX-XXXX` | `+972 50 XXX XXXX` |
| VoIP (07X) | `077-XXX-XXXX` | `+972 77 XXX XXXX` |
| Toll-free (domestic only) | `1-800-XXX-XXX` | `not reachable from abroad` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+97235551234` | `+972 3 555 1234` | `03-555-1234` | Tel Aviv — area code 03 covers Tel Aviv and the Central District |
| fixed-line | `+97226665678` | `+972 2 666 5678` | `02-666-5678` | Jerusalem — area code 02 |
| mobile | `+972501234567` | `+972 50 123 4567` | `050-123-4567` | Mobile — 050 is a Pelephone range; 050–059 are all mobile |

## Notes

- International access can be dialled as 00 or via a carrier-specific code (012, 013, 014, 018), each billed differently.
- 1-800 toll-free numbers work only from inside Israel.
- The +972 code is also used for Palestinian numbers in some contexts; the State of Palestine additionally holds +970.
