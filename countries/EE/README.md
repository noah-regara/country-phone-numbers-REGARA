# Estonia — Phone Number Formats

**ISO 3166-1:** `EE` / `EST`  
**Country calling code:** +372  
**Trunk prefix:** none  
**International call prefix:** `00`  
**National significant number:** 7 or 8 digits

## Formatting

```
National:      XXX XXXX (fixed) / XXXX XXXX (mobile)
International: +372 XXX XXXX
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Fixed line (3xx–7xx) | `XXX XXXX` | `+372 XXX XXXX` |
| Mobile (5xxx) | `5XXX XXXX` | `+372 5XXX XXXX` |
| Freephone | `800 XXXX` | `+372 800 XXXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+3727992222` | `+372 799 2222` | `799 2222` | Tallinn — fixed lines are 7 digits |
| mobile | `+37251234567` | `+372 5123 4567` | `5123 4567` | Mobile — all Estonian mobiles begin with 5 |
| fixed-line | `+3723441234` | `+372 344 1234` | `344 1234` | Narva region fixed line |

## Notes

- Estonia moved to a closed plan on 2003-05-01, abolishing area codes and the trunk prefix; every call within Estonia is dialled as a plain local number.
- Fixed lines are 7 digits; mobile numbers are 7 or 8 digits and always start with 5.
