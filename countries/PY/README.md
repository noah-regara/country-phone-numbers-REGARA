# Paraguay — Phone Number Formats

**ISO 3166-1:** `PY` / `PRY`  
**Country calling code:** +595  
**Trunk prefix:** `0`  
**International call prefix:** `00`  
**National significant number:** variable

## Formatting

```
National:      (0AA) XXXXXX (landline) / (09XX) XXXXXX (mobile)
International: +595 AA XXXXXX (trunk 0 dropped)
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Asunción (21) | `(021) XXXXXX` | `+595 21 XXXXXX` |
| Other areas (2–3 digit area codes) | `(0XXX) XXXXXX` | `+595 XXX XXXXXX` |
| Mobile — Claro (991–995), Personal (971–976), Tigo (981–985), VOX (961, 963) | `(0991) XXXXXX` | `+595 991 XXXXXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+59521123456` | `+595 21 123456` | `(021) 123456` | Asunción — area code 21 |
| mobile | `+595991123456` | `+595 991 123456` | `(0991) 123456` | Mobile — 991 is a Claro Paraguay range |
| mobile | `+595981123456` | `+595 981 123456` | `(0981) 123456` | Mobile — 981 is a Tigo range |

## Notes

- Area codes are 2–3 digits and subscriber numbers 6–7, so NSN length varies between 8 and 9 digits.
- All mobile prefixes begin with 9.
