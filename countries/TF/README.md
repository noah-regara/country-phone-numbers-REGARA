# French Southern Territories — Phone Number Formats

**ISO 3166-1:** `TF` / `ATF`  
**Country calling code:** +262  
**Trunk prefix:** `0`  
**International call prefix:** `00`  
**National significant number:** variable

## Formatting

```
National:      no public numbering
International: administered under +262 (Réunion)
```

## Examples

_No public numbering is assigned to this territory — see the notes below._

## Notes

- The French Southern and Antarctic Lands have no permanent civilian population — only rotating scientific and military staff at bases on the Kerguelen and Crozet islands, Amsterdam Island and Adélie Land.
- The territory is administered from Réunion and falls nominally under +262, but no public subscriber numbers are allocated.
- Station communications run over satellite links operated by the French polar institute IPEV and the territorial administration.
