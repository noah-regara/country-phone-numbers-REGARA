# Qatar — Phone Number Formats

**ISO 3166-1:** `QA` / `QAT`  
**Country calling code:** +974  
**Trunk prefix:** none  
**International call prefix:** `00`  
**National significant number:** 8 digits

## Formatting

```
National:      XXXX XXXX
International: +974 XXXX XXXX
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Fixed line (4) | `44XX XXXX` | `+974 44XX XXXX` |
| Mobile (3, 5, 6, 7) | `33XX XXXX` | `+974 33XX XXXX` |
| Freephone | `800 XXXX` | `+974 800 XXXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+97444123456` | `+974 4412 3456` | `4412 3456` | Fixed line — Qatari landlines begin with 4 (Ooredoo) |
| mobile | `+97433123456` | `+974 3312 3456` | `3312 3456` | Mobile — 3 is an Ooredoo range |
| mobile | `+97477123456` | `+974 7712 3456` | `7712 3456` | Mobile — 7 is a Vodafone Qatar range |

## Notes

- Qatar introduced its current plan in 2010, standardising most numbers at 8 digits.
- No area codes or trunk prefix. Mobile numbers begin 3, 5, 6 or 7; fixed lines begin 4.
- Special services (emergency 99, freephone 800, audiotext 900) use shorter numbers.
