# Guyana — Phone Number Formats

**ISO 3166-1:** `GY` / `GUY`  
**Country calling code:** +592  
**Trunk prefix:** none  
**International call prefix:** `001`  
**National significant number:** 7 digits

## Formatting

```
National:      XXX-XXXX
International: +592 XXX XXXX
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Georgetown fixed (22X, 23X) | `223-XXXX` | `+592 223 XXXX` |
| Mobile (600–699) | `624-XXXX` | `+592 624 XXXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+5922231234` | `+592 223 1234` | `223-1234` | Georgetown — the 223 billing prefix serves the capital |
| mobile | `+5926245678` | `+592 624 5678` | `624-5678` | Mobile — the 600–699 range has been GSM-only since 2007-12-01 |

## Notes

- All numbers are 7 digits: a 3-digit billing prefix plus a 4-digit directory number.
- Prefixes are allocated by geography for fixed lines and by service type for mobile and special numbers.
