# Heard Island and McDonald Islands — Phone Number Formats

**ISO 3166-1:** `HM` / `HMD`  
**Country calling code:** +672  
**Trunk prefix:** none  
**International call prefix:** `00`  
**National significant number:** variable

## Formatting

```
National:      no numbering assigned
International: no numbering assigned
```

## Examples

_No public numbering is assigned to this territory — see the notes below._

## Notes

- Heard Island and McDonald Islands form an uninhabited Australian external territory in the subantarctic. There is no permanent population and no exchange.
- The territory is nominally associated with +672, the Australian Antarctic code, but no numbers are allocated to it.
- Australian Antarctic Division expeditions that visit communicate by satellite.
