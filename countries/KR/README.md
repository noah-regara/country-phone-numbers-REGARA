# Korea, Republic of — Phone Number Formats

**ISO 3166-1:** `KR` / `KOR`  
**Country calling code:** +82  
**Trunk prefix:** `0`  
**International call prefix:** `00X (carrier-selected, e.g. 001, 002, 00700)`  
**National significant number:** 8 or 9 or 10 digits

## Formatting

```
National:      0A-XXX-XXXX (Seoul) / 0AA-XXX-XXXX (elsewhere)
International: +82 A XXX XXXX (trunk 0 dropped)
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Seoul (02) | `02-XXX-XXXX` | `+82 2 XXX XXXX` |
| Busan (051), Incheon (032), Daegu (053) | `051-XXX-XXXX` | `+82 51 XXX XXXX` |
| Mobile (010) | `010-XXXX-XXXX` | `+82 10 XXXX XXXX` |
| Nationwide single number | `1577-XXXX` | `+82 1577 XXXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+8223123456` | `+82 2 312 3456` | `02-312-3456` | Seoul — area code 02, the only single-digit code |
| fixed-line | `+82511234567` | `+82 51 123 4567` | `051-123-4567` | Busan — area code 051 |
| mobile | `+821012345678` | `+82 10 1234 5678` | `010-1234-5678` | Mobile — since 2004-01-01 all South Korean mobiles use the single 010 prefix |

## Notes

- Since 2004 every South Korean mobile number uses the 010 prefix regardless of carrier, replacing the old per-operator prefixes (011, 016, 017, 018, 019).
- The international access prefix is carrier-selected — 001, 002, 00700 and others all work and are billed differently.
- Seoul has the single-digit area code 2; other regions have two digits.
