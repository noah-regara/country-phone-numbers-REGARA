# Kazakhstan — Phone Number Formats

**ISO 3166-1:** `KZ` / `KAZ`  
**Country calling code:** +7  
**Trunk prefix:** `8`  
**International call prefix:** `810`  
**National significant number:** 10 digits

## Formatting

```
National:      8 (AAA) XXX XX XX
International: +7 AAA XXX XX XX
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Almaty (727), Astana (717) | `8 (727) XXX XX XX` | `+7 727 XXX XX XX` |
| Other regions (zone codes 710–729) | `8 (7XX) XXX XX XX` | `+7 7XX XXX XX XX` |
| Mobile (70X, 77X) | `8 (701) XXX XX XX` | `+7 701 XXX XX XX` |
| Non-geographic (75X, 76X) | `8 (75X) XXX XX XX` | `+7 75X XXX XX XX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+77271234567` | `+7 727 123 45 67` | `8 (727) 123 45 67` | Almaty — zone code 727 |
| fixed-line | `+77171234567` | `+7 717 123 45 67` | `8 (717) 123 45 67` | Astana — zone code 717 |
| mobile | `+77011234567` | `+7 701 123 45 67` | `8 (701) 123 45 67` | Mobile — 70X and 77X ranges |

## Notes

- Kazakhstan shares country code +7 with Russia; the two are distinguished by zone code, with Kazakhstan holding 6xx and 7xx blocks.
- Kazakhstan planned to adopt its own code (+997) but confirmed continued code-sharing with Russia in a November 2023 agreement.
- Trunk prefix 8 and international access 8~10 follow the Soviet-era convention retained across the region.
- Geographic zone codes 710–729 were assigned by region under a 2006 agreement with Russia.
