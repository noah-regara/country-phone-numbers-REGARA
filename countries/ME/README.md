# Montenegro — Phone Number Formats

**ISO 3166-1:** `ME` / `MNE`  
**Country calling code:** +382  
**Trunk prefix:** `0`  
**International call prefix:** `00`  
**National significant number:** 8 digits

## Formatting

```
National:      0AA XXX XXX
International: +382 AA XXX XXX (trunk 0 dropped)
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Podgorica (020) | `020 XXX XXX` | `+382 20 XXX XXX` |
| Other geographic (030–052) | `0XX XXX XXX` | `+382 XX XXX XXX` |
| Mobile (060–069) | `067 XXX XXX` | `+382 67 XXX XXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+38220123456` | `+382 20 123 456` | `020 123 456` | Podgorica — area code 20 also covers Danilovgrad and Kolašin |
| mobile | `+38267123456` | `+382 67 123 456` | `067 123 456` | Mobile — 06x ranges |
| mobile | `+38260123456` | `+382 60 123 456` | `060 123 456` | Mobile — 60 is an m:tel range |

## Notes

- Montenegro took country code +382 after independence; the shared Serbian +381 was fully phased out by October 2007.
- Closed plan with 8-digit NSNs: 2-digit area code plus 6-digit subscriber number.
