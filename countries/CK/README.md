# Cook Islands — Phone Number Formats

**ISO 3166-1:** `CK` / `COK`  
**Country calling code:** +682  
**Trunk prefix:** none  
**International call prefix:** `00`  
**National significant number:** 5 digits

## Formatting

```
National:      XX XXX
International: +682 XX XXX
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Fixed line — Rarotonga (2XXXX) | `2XXXX` | `+682 2XXXX` |
| Mobile (50–59, 7XXXX, 8XXXX) | `5XXXX` | `+682 5XXXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+68221234` | `+682 21 234` | `21234` | Rarotonga — the 2 prefix routes to the main island subscriber network |
| mobile | `+68251234` | `+682 51 234` | `51234` | Mobile — the 5X range |

## Notes

- The Cook Islands use a short 5-digit NSN with no trunk prefix or area codes.
- Self-governing in free association with New Zealand, but with its own country code +682 rather than sharing +64.
