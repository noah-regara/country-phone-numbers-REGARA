# Nauru — Phone Number Formats

**ISO 3166-1:** `NR` / `NRU`  
**Country calling code:** +674  
**Trunk prefix:** none  
**International call prefix:** `00`  
**National significant number:** 7 digits

## Formatting

```
National:      XXX XXXX
International: +674 XXX XXXX
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Mobile (556, 557, 558) | `556 XXXX` | `+674 556 XXXX` |
| Fixed line (444, 555) — largely out of service | `444 XXXX` | `+674 444 XXXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| mobile | `+6745561234` | `+674 556 1234` | `556 1234` | Mobile — 556/557/558 are the ranges actually in service |
| fixed-line | `+6744445678` | `+674 444 5678` | `444 5678` | Legacy landline range; Nauru reported no landlines in service as of 2011 |

## Notes

- Nauru is effectively mobile-only: the regulator has reported that only the 556, 557 and 558 ranges are in use and that no landlines remain in service.
- Closed 7-digit plan with no trunk prefix or area codes.
