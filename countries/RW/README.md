# Rwanda — Phone Number Formats

**ISO 3166-1:** `RW` / `RWA`  
**Country calling code:** +250  
**Trunk prefix:** `0`  
**International call prefix:** `00`  
**National significant number:** 9 digits

## Formatting

```
National:      0NNN XXX XXX
International: +250 NNN XXX XXX
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Fixed line (25X) | `0250 XXX XXX` | `+250 250 XXX XXX` |
| Mobile — MTN (078, 079), Airtel (073, 072) | `0788 XXX XXX` | `+250 788 XXX XXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+250250512345` | `+250 250 512 345` | `0250 512 345` | Kigali — geographic landlines begin with 25 |
| mobile | `+250788123456` | `+250 788 123 456` | `0788 123 456` | Mobile — 78 is an MTN Rwanda range |
| mobile | `+250730123456` | `+250 730 123 456` | `0730 123 456` | Mobile — 73 range |

## Notes

- The Rwanda Utilities Regulatory Authority introduced the current numbering plan in February 2009.
- The NSN is 9 digits: a 3-digit national destination code plus a 6-digit subscriber number.
- Mobile prefixes are 72, 73 and 78; geographic landlines begin 25.
