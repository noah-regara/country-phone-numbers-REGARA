# Lao People's Democratic Republic — Phone Number Formats

**ISO 3166-1:** `LA` / `LAO`  
**Country calling code:** +856  
**Trunk prefix:** `0`  
**International call prefix:** `00`  
**National significant number:** variable

## Formatting

```
National:      0AA XXXXXX (fixed) / 020 XXXXXXXX (mobile)
International: +856 AA XXXXXX (trunk 0 dropped)
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Vientiane Prefecture (021) | `021 XXXXXX` | `+856 21 XXXXXX` |
| Other provinces (2-digit area codes) | `0XX XXXXXX` | `+856 XX XXXXXX` |
| Mobile (020) | `020 XXXXXXXX` | `+856 20 XXXXXXXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+85621123456` | `+856 21 123456` | `021 123456` | Vientiane Prefecture — area code 021 |
| mobile | `+8562012345678` | `+856 20 1234 5678` | `020 1234 5678` | Mobile — all Lao mobiles use the 020 prefix with an 8-digit subscriber number |

## Notes

- Fixed NSNs are around 8 digits while mobile NSNs are 10, so length varies considerably.
- Direct dialling to other provinces and countries without operator assistance has been available since January 2012.
