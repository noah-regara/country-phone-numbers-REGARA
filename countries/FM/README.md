# Micronesia, Federated States of — Phone Number Formats

**ISO 3166-1:** `FM` / `FSM`  
**Country calling code:** +691  
**Trunk prefix:** none  
**International call prefix:** `011`  
**National significant number:** 7 digits

## Formatting

```
National:      XXX XXXX
International: +691 XXX XXXX
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Pohnpei (320, 920) | `320 XXXX` | `+691 320 XXXX` |
| Chuuk (330, 930), Yap (350, 950), Kosrae (370, 970) | `330 XXXX` | `+691 330 XXXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+6919201234` | `+691 920 1234` | `920 1234` | Pohnpei — the 920 prefix |
| mobile | `+6919305678` | `+691 930 5678` | `930 5678` | Chuuk — the 930 prefix |

## Notes

- The current plan dates from 2003, with prefixes assigned by state (Pohnpei, Chuuk, Yap, Kosrae) and by service type.
- The international access prefix is 011, inherited from US practice, though the FSM is not part of the NANP.
