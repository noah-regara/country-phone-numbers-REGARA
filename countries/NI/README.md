# Nicaragua — Phone Number Formats

**ISO 3166-1:** `NI` / `NIC`  
**Country calling code:** +505  
**Trunk prefix:** none  
**International call prefix:** `00`  
**National significant number:** 8 digits

## Formatting

```
National:      XXXX XXXX
International: +505 XXXX XXXX
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Fixed line (2) | `2XXX XXXX` | `+505 2XXX XXXX` |
| Mobile (5, 7, 8) | `8XXX XXXX` | `+505 8XXX XXXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+50522345678` | `+505 2234 5678` | `2234 5678` | Fixed line — leading 2 |
| mobile | `+50581234567` | `+505 8123 4567` | `8123 4567` | Mobile — 5, 7 and 8 prefixes |

## Notes

- Nicaragua moved from 7 to 8 digits in 2009 by prefixing 2 for fixed lines and 5/7/8 for mobile.
- Closed plan with no area codes or trunk prefix.
