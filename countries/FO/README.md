# Faroe Islands — Phone Number Formats

**ISO 3166-1:** `FO` / `FRO`  
**Country calling code:** +298  
**Trunk prefix:** none  
**International call prefix:** `00`  
**National significant number:** 6 digits

## Formatting

```
National:      XX XX XX
International: +298 XX XX XX
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Fixed line (3x) | `3X XX XX` | `+298 3X XX XX` |
| Mobile (2x, 5x, 7x) | `2X XX XX` | `+298 2X XX XX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+298302010` | `+298 30 20 10` | `30 20 10` | Tórshavn — fixed network ranges begin with 3 |
| mobile | `+298211234` | `+298 21 12 34` | `21 12 34` | Mobile — 21 is a GSM range |

## Notes

- The Faroe Islands are a self-governing part of Denmark but have their own country code +298, separate from Denmark's +45.
- All numbers are 6 digits with no trunk prefix or area codes, written as three pairs.
- The islands received a code beginning with 2 (a range normally allocated to Africa) because the European 3xx and 4xx ranges were exhausted.
