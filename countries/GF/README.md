# French Guiana — Phone Number Formats

**ISO 3166-1:** `GF` / `GUF`  
**Country calling code:** +594  
**Trunk prefix:** `0`  
**International call prefix:** `00`  
**National significant number:** 9 digits

## Formatting

```
National:      0594 XX XX XX
International: +594 594 XX XX XX
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Fixed line (0594) | `0594 XX XX XX` | `+594 594 XX XX XX` |
| Mobile (0694) | `0694 XX XX XX` | `+594 694 XX XX XX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+594594123456` | `+594 594 12 34 56` | `0594 12 34 56` | French Guiana fixed — country code repeats as the internal area code |
| mobile | `+594694123456` | `+594 694 12 34 56` | `0694 12 34 56` | Mobile — the 0694 range |

## Notes

- French Guiana is an overseas department using the French 10-digit national format.
- Numbers are written in pairs in the French style.
