# Cabo Verde — Phone Number Formats

**ISO 3166-1:** `CV` / `CPV`  
**Country calling code:** +238  
**Trunk prefix:** none  
**International call prefix:** `00`  
**National significant number:** 7 digits

## Formatting

```
National:      XXX XXXX
International: +238 XXX XXXX
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Fixed line — Santiago/Praia (26X) | `26X XXXX` | `+238 26X XXXX` |
| Mobile (9XX) | `9XX XXXX` | `+238 9XX XXXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+2382601234` | `+238 260 1234` | `260 1234` | Praia — the first three digits of a fixed number encode the geographic area (26 = Santiago) |
| mobile | `+2389912345` | `+238 991 2345` | `991 2345` | Mobile — the 9 prefix carries no geographic meaning |

## Notes

- Closed 7-digit plan restructured on 2004-07-03 by prepending digits to the older shorter numbers.
- Fixed numbers encode geography in their first three digits; mobile numbers do not.
