# Gambia — Phone Number Formats

**ISO 3166-1:** `GM` / `GMB`  
**Country calling code:** +220  
**Trunk prefix:** none  
**International call prefix:** `00`  
**National significant number:** 7 digits

## Formatting

```
National:      XXX XXXX
International: +220 XXX XXXX
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Fixed line — GAMTEL (42X–44X) | `42X XXXX` | `+220 42X XXXX` |
| Mobile — Africell (2XX), QCell (3XX), Comium (7XX), Gamcel (9XX) | `2XX XXXX` | `+220 2XX XXXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+2204221234` | `+220 422 1234` | `422 1234` | Banjul — the 42X GAMTEL fixed allocation |
| mobile | `+2202991234` | `+220 299 1234` | `299 1234` | Mobile — the 2XX Africell allocation |

## Notes

- Closed 7-digit plan with no trunk prefix; numbers are dialled directly within the country.
- The leading digit identifies the operator rather than a geographic area.
