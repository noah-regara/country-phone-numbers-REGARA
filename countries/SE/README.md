# Sweden — Phone Number Formats

**ISO 3166-1:** `SE` / `SWE`  
**Country calling code:** +46  
**Trunk prefix:** `0`  
**International call prefix:** `00`  
**National significant number:** variable

## Formatting

```
National:      0AA-XXX XX XX (open plan, variable length)
International: +46 AA XXX XX XX (trunk 0 dropped)
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Stockholm (08) | `08-XXX XX XX` | `+46 8 XXX XX XX` |
| Gothenburg (031), Malmö (040) | `031-XXX XX XX` | `+46 31 XXX XX XX` |
| Mobile (07x) | `070-XXX XX XX` | `+46 70 XXX XX XX` |
| Freephone | `020-XXX XXX` | `+46 20 XXX XXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+4681234567` | `+46 8 123 45 67` | `08-123 45 67` | Stockholm — area code 08, the shortest in the country |
| fixed-line | `+4631123456` | `+46 31 123 456` | `031-123 456` | Gothenburg — area code 031 |
| mobile | `+46701234567` | `+46 70 123 45 67` | `070-123 45 67` | Mobile — 07x ranges |
| toll-free | `+4620123456` | `+46 20 123 456` | `020-123 456` | Freephone — not reachable from outside Sweden |

## Notes

- Sweden has an open numbering plan: area codes are 2–4 digits including the trunk 0, and NSN length varies (roughly 7–13 digits).
- Larger cities get shorter area codes — Stockholm is 08, Gothenburg 031, and rural areas run to four digits.
- The hyphen after the area code is the conventional Swedish written separator.
- 020 freephone numbers generally cannot be reached from abroad.
