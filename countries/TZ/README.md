# Tanzania, United Republic of — Phone Number Formats

**ISO 3166-1:** `TZ` / `TZA`  
**Country calling code:** +255  
**Trunk prefix:** `0`  
**International call prefix:** `000`  
**National significant number:** 9 digits

## Formatting

```
National:      0AA XXX XXXX
International: +255 AA XXX XXXX (trunk 0 dropped)
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Dar es Salaam (022) | `022 XXX XXXX` | `+255 22 XXX XXXX` |
| Other regions (2X, 4X geographic) | `0XX XXX XXXX` | `+255 XX XXX XXXX` |
| Mobile (06X, 07X) | `074 XXX XXXX` | `+255 74 XXX XXXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+255221234567` | `+255 22 123 4567` | `022 123 4567` | Dar es Salaam — area code 22 |
| mobile | `+255741234567` | `+255 74 123 4567` | `074 123 4567` | Mobile — 74 is a Vodacom Tanzania range |
| mobile | `+255651234567` | `+255 65 123 4567` | `065 123 4567` | Mobile — 65 range |

## Notes

- Tanzania adopted its own numbering plan in 1999, replacing a system shared with Kenya and Uganda.
- Zanzibar is part of Tanzania and uses the same +255 plan (area code 024).
- The international access prefix is 000.
