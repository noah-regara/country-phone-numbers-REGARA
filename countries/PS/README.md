# Palestine, State of — Phone Number Formats

**ISO 3166-1:** `PS` / `PSE`  
**Country calling code:** +970, +972  
**Trunk prefix:** `0`  
**International call prefix:** `00`  
**National significant number:** 8 or 9 digits

## Formatting

```
National:      0A XXX XXXX (landline) / 05X XXX XXXX (mobile)
International: +970 A XXX XXXX — often also reachable as +972 A XXX XXXX
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| West Bank — Ramallah/Jerusalem (02), Nablus (09), Hebron (02) | `02 XXX XXXX` | `+970 2 XXX XXXX` |
| Gaza Strip (08) | `08 XXX XXXX` | `+970 8 XXX XXXX` |
| Mobile — Jawwal (059), Ooredoo (056) | `059 XXX XXXX` | `+970 59 XXX XXXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+97022951234` | `+970 2 295 1234` | `02 295 1234` | Ramallah, West Bank — area code 02 |
| fixed-line | `+97082821234` | `+970 8 282 1234` | `08 282 1234` | Gaza City — area code 08 |
| mobile | `+970599123456` | `+970 59 912 3456` | `059 912 3456` | Mobile — 059 is a Jawwal range |

## Notes

- Palestine holds country code +970, but because the network depends heavily on Israeli infrastructure many Palestinian numbers are also reachable via +972 — and from some countries +972 routes more reliably.
- Any system validating Palestinian numbers should accept both +970 and +972 forms.
- Area code 02 spans Ramallah, Jerusalem and Hebron; 08 covers the Gaza Strip; 09 covers Nablus and the northern West Bank.
