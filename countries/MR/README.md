# Mauritania — Phone Number Formats

**ISO 3166-1:** `MR` / `MRT`  
**Country calling code:** +222  
**Trunk prefix:** none  
**International call prefix:** `00`  
**National significant number:** 8 digits

## Formatting

```
National:      XXXX XXXX
International: +222 XXXX XXXX
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Fixed line — Nouakchott (45) | `45XX XXXX` | `+222 45XX XXXX` |
| Mobile — Chinguitel (24), Mauritel (2X, 3X), Mattel (4X) | `24XX XXXX` | `+222 24XX XXXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+22245123456` | `+222 4512 3456` | `4512 3456` | Nouakchott — the 45 fixed prefix |
| mobile | `+22224123456` | `+222 2412 3456` | `2412 3456` | Mobile — the 24 prefix belongs to Chinguitel |

## Notes

- Mauritania moved from 7-digit to 8-digit NSNs in 2011.
- No trunk prefix or area codes; the leading pair identifies the operator and service.
