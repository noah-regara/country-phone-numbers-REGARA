# Cambodia — Phone Number Formats

**ISO 3166-1:** `KH` / `KHM`  
**Country calling code:** +855  
**Trunk prefix:** `0`  
**International call prefix:** `00`  
**National significant number:** 8 or 9 digits

## Formatting

```
National:      0AA-XXX-XXX (landline) / 0AA-XXX-XXXX (mobile)
International: +855 AA XXX XXX (trunk 0 dropped)
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Phnom Penh (023) | `023-XXX-XXX` | `+855 23 XXX XXX` |
| Provincial (2-digit area codes) | `0XX-XXX-XXX` | `+855 XX XXX XXX` |
| Mobile (010, 011, 012, 015–017, 06x, 07x, 08x, 09x) | `010-XXX-XXXX` | `+855 10 XXX XXXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+85523123456` | `+855 23 123 456` | `023-123-456` | Phnom Penh — area code 023 |
| mobile | `+855102345678` | `+855 10 234 5678` | `010-234-5678` | Mobile — 010 is a Smart Axiata range |
| mobile | `+855882345678` | `+855 88 234 5678` | `088-234-5678` | Mobile — 088 is a Metfone range |

## Notes

- Cambodia uses a closed plan compliant with ITU-T E.164; the leading 0 is dropped when dialling from abroad.
- The first two digits after the trunk 0 identify the operator for mobile numbers.
- Mobile NSNs run 8–9 digits depending on the operator's allocated block.
