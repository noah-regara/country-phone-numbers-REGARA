# Russian Federation — Phone Number Formats

**ISO 3166-1:** `RU` / `RUS`  
**Country calling code:** +7  
**Trunk prefix:** `8`  
**International call prefix:** `810`  
**National significant number:** 10 digits

## Formatting

```
National:      8 AAA XXX-XX-XX
International: +7 AAA XXX XX XX
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Moscow (495, 499) | `8 495 XXX-XX-XX` | `+7 495 XXX XX XX` |
| Saint Petersburg (812) | `8 812 XXX-XX-XX` | `+7 812 XXX XX XX` |
| Mobile (9XX) | `8 985 XXX-XX-XX` | `+7 985 XXX XX XX` |
| Freephone | `8 800 XXX-XX-XX` | `+7 800 XXX XX XX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+74951234567` | `+7 495 123 45 67` | `8 495 123-45-67` | Moscow — area code 495 (499 is the overlay) |
| fixed-line | `+78121234567` | `+7 812 123 45 67` | `8 812 123-45-67` | Saint Petersburg — area code 812 |
| mobile | `+79851234567` | `+7 985 123 45 67` | `8 985 123-45-67` | Mobile — all Russian mobile codes begin with 9 |
| toll-free | `+78001234567` | `+7 800 123 45 67` | `8 800 123-45-67` | Freephone |

## Notes

- Russia shares country code +7 with Kazakhstan — the code alone does not identify the country.
- The trunk prefix is 8 (not 0) and the international access code is 8~10, dialled as 8 then 10 after a second dial tone.
- Closed plan: NSN is always 10 digits (3-digit area code + 7-digit subscriber number).
- All mobile area codes begin with 9, which is the reliable way to distinguish mobile from fixed.
