# Somalia — Phone Number Formats

**ISO 3166-1:** `SO` / `SOM`  
**Country calling code:** +252  
**Trunk prefix:** `0`  
**International call prefix:** `00`  
**National significant number:** variable

## Formatting

```
National:      0YX XXX XXX
International: +252 YX XXX XXX (trunk 0 dropped)
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Fixed line — Mogadishu (021) and Federal Member State codes (02X) | `021 XXX XXX` | `+252 21 XXX XXX` |
| Mobile — Hormuud, Somtel, Telesom (6X, 7X–9X) | `061 XXX XXX` | `+252 61 XXX XXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+25221123456` | `+252 21 123 456` | `021 123 456` | Mogadishu — area code 21 |
| mobile | `+25261123456` | `+252 61 123 456` | `061 123 456` | Mobile — 61 is a Hormuud range |

## Notes

- Somali numbering was largely unregulated between 1991 and the establishment of the National Communications Authority in 2017; NSN length is inconsistent across operators, so length-based validation is unreliable.
- Fixed-line area codes were standardised in 2021 around an 02X series for the Federal Member States.
- Somaliland, which declares independence but is internationally recognised as part of Somalia, also uses +252 — the country code does not distinguish the two.
