# Eritrea — Phone Number Formats

**ISO 3166-1:** `ER` / `ERI`  
**Country calling code:** +291  
**Trunk prefix:** `0`  
**International call prefix:** `00`  
**National significant number:** 7 digits

## Formatting

```
National:      0A XXXXXX
International: +291 A XXXXXX (trunk 0 dropped)
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Fixed line — Asmara (1) | `01 XXXXXX` | `+291 1 XXXXXX` |
| Mobile (7) | `07 XXXXXX` | `+291 7 XXXXXX` |
| Fixed CDMA (8) | `08 XXXXXX` | `+291 8 XXXXXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+2911123456` | `+291 1 123456` | `01 123456` | Asmara — area code 1 |
| mobile | `+2917123456` | `+291 7 123456` | `07 123456` | Mobile — the 7 range, in service since May 2001 |

## Notes

- Eritrea uses a single-digit area or service code followed by a 6-digit subscriber number.
- Mobile allocations date from 2004 and fixed CDMA allocations from 2009; telecommunications are operated by the state monopoly EriTel.
