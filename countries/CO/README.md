# Colombia — Phone Number Formats

**ISO 3166-1:** `CO` / `COL`  
**Country calling code:** +57  
**Trunk prefix:** `0 + carrier code`  
**International call prefix:** `00 + carrier code`  
**National significant number:** 10 digits

## Formatting

```
National:      60B XXX XXXX (landline) / 3XX XXX XXXX (mobile)
International: +57 60B XXX XXXX
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Bogotá (601), Medellín (604), Cali (602) | `601 XXX XXXX` | `+57 601 XXX XXXX` |
| Mobile (3XX) | `310 XXX XXXX` | `+57 310 XXX XXXX` |
| Toll-free | `01 8000 XXXXXX` | `not reachable from abroad` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+576012345678` | `+57 601 234 5678` | `601 234 5678` | Bogotá — the 601 prefix covers Bogotá and Cundinamarca |
| fixed-line | `+576042345678` | `+57 604 234 5678` | `604 234 5678` | Medellín and Antioquia — prefix 604 |
| mobile | `+573105678901` | `+57 310 567 8901` | `310 567 8901` | Mobile — 3XX ranges; 310 is a Claro range |

## Notes

- Colombia renumbered in September 2021–2022: the old single-digit dialling zones with 7-digit local numbers became uniform 10-digit numbers by inserting '60' in front of the zone digit.
- So the old Bogotá (1) 234 5678 is now 601 234 5678.
- Mobile numbers were already 10 digits and were unaffected by the reform.
