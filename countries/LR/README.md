# Liberia — Phone Number Formats

**ISO 3166-1:** `LR` / `LBR`  
**Country calling code:** +231  
**Trunk prefix:** none  
**International call prefix:** `00`  
**National significant number:** variable

## Formatting

```
National:      XX XXX XXXX (variable)
International: +231 XX XXX XXXX
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Fixed line — LIBTELCO (2X) | `2 XXXXXXX` | `+231 2 XXXXXXX` |
| Mobile — Orange (77X), Lonestar/MTN (88X) | `77 XXXXXXX` | `+231 77 XXXXXXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+23121234567` | `+231 2 123 4567` | `2 123 4567` | Monrovia — the 2X fixed range operated by LIBTELCO |
| mobile | `+231771234567` | `+231 77 123 4567` | `77 123 4567` | Mobile — 77X is an Orange Liberia range |

## Notes

- Liberian NSNs run 7–9 digits depending on the service, so length alone cannot validate a number.
- Mobile numbers dominate; fixed-line coverage is limited.
