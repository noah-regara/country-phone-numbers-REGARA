# Norfolk Island — Phone Number Formats

**ISO 3166-1:** `NF` / `NFK`  
**Country calling code:** +672  
**Trunk prefix:** none  
**International call prefix:** `00`  
**National significant number:** 6 digits

## Formatting

```
National:      3 XX XXX
International: +672 3 XX XXX
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Fixed line (3 2X XXX) | `3 2X XXX` | `+672 3 2X XXX` |
| Mobile (3 5X XXX) | `3 5X XXX` | `+672 3 5X XXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+672322123` | `+672 3 22 123` | `3 22 123` | Norfolk Island — area code 3 within +672, fixed range 2X |
| mobile | `+672351234` | `+672 3 51 234` | `3 51 234` | Mobile — the 5X range |

## Notes

- Norfolk Island shares country code +672 with the Australian Antarctic Territory, taking area code 3.
- Christmas Island and the Cocos (Keeling) Islands also used +672 until October 1994, when they migrated to +61.
- +672 was assigned to Portuguese Timor until 1975, and +672 9 was used for Timor-Leste under an interim arrangement after 1999.
