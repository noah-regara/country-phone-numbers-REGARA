# Iceland — Phone Number Formats

**ISO 3166-1:** `IS` / `ISL`  
**Country calling code:** +354  
**Trunk prefix:** none  
**International call prefix:** `00`  
**National significant number:** 7 or 9 digits

## Formatting

```
National:      XXX XXXX
International: +354 XXX XXXX
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Fixed line (Capital Region 5xx, regional 4xx) | `5XX XXXX` | `+354 5XX XXXX` |
| Mobile (6xx, 7xx, 8xx) | `8XX XXXX` | `+354 8XX XXXX` |
| Freephone | `800 XXXX` | `+354 800 XXXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+3545512345` | `+354 551 2345` | `551 2345` | Reykjavík — 5xx is the Capital Region fixed range |
| mobile | `+3548215678` | `+354 821 5678` | `821 5678` | Mobile — 6xx/7xx/8xx ranges |
| toll-free | `+3548001234` | `+354 800 1234` | `800 1234` | Freephone |

## Notes

- Iceland uses a closed 7-digit plan with no trunk prefix or area codes; numbers beginning with 3 are 9 digits.
- Number portability means the leading digits no longer reliably indicate operator or region.
