# Central African Republic — Phone Number Formats

**ISO 3166-1:** `CF` / `CAF`  
**Country calling code:** +236  
**Trunk prefix:** none  
**International call prefix:** `00`  
**National significant number:** 8 digits

## Formatting

```
National:      XXXX XXXX
International: +236 XXXX XXXX
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Fixed line — Socatel, Bangui (21) | `21XX XXXX` | `+236 21XX XXXX` |
| Mobile — Orange, Telecel, Nationlink, Acell (70, 72, 75, 77) | `70XX XXXX` | `+236 70XX XXXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+23621123456` | `+236 2112 3456` | `2112 3456` | Bangui — the 21 prefix is Socatel's fixed service |
| mobile | `+23670123456` | `+236 7012 3456` | `7012 3456` | Mobile — the 70 range |

## Notes

- On 2007-11-01 the Central African Republic expanded from 6 to 8 digits to align with ITU-T E.164.
- No trunk prefix; the full 8 digits are dialled for every call.
