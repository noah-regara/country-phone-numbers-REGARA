# Lesotho — Phone Number Formats

**ISO 3166-1:** `LS` / `LSO`  
**Country calling code:** +266  
**Trunk prefix:** none  
**International call prefix:** `00`  
**National significant number:** 8 digits

## Formatting

```
National:      XX XXX XXX
International: +266 XX XXX XXX
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Maseru fixed (22, 28) | `22 XXX XXX` | `+266 22 XXX XXX` |
| Mobile (56, 57, 58, 59, 63, 6x) | `58 XXX XXX` | `+266 58 XXX XXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+26622123456` | `+266 22 123 456` | `22 123 456` | Maseru — fixed prefixes 22 and 28 |
| mobile | `+26658123456` | `+266 58 123 456` | `58 123 456` | Mobile — 5x and 6x ranges |

## Notes

- Closed 8-digit plan with no trunk prefix or area codes; the leading pair identifies the service.
- Before independence-era renumbering, Lesotho was reached from South Africa via the regional code 050.
