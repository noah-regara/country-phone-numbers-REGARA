# Wallis and Futuna — Phone Number Formats

**ISO 3166-1:** `WF` / `WLF`  
**Country calling code:** +681  
**Trunk prefix:** none  
**International call prefix:** `00`  
**National significant number:** 6 digits

## Formatting

```
National:      XX XX XX
International: +681 XX XX XX
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Fixed line (72 XXXX) | `72 XX XX` | `+681 72 XX XX` |
| Mobile (82 XXXX, 83 XXXX) | `82 XX XX` | `+681 82 XX XX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+681721234` | `+681 72 12 34` | `72 12 34` | Fixed line — the 72 prefix |
| mobile | `+681821234` | `+681 82 12 34` | `82 12 34` | Mobile — the 82/83 prefixes |

## Notes

- Wallis and Futuna is a French overseas collectivity but keeps its own country code +681 rather than joining the French plan.
- All numbers are 6 digits with no trunk prefix; they are written in pairs in the French style.
