# Angola — Phone Number Formats

**ISO 3166-1:** `AO` / `AGO`  
**Country calling code:** +244  
**Trunk prefix:** none  
**International call prefix:** `00`  
**National significant number:** 9 digits

## Formatting

```
National:      XXX XXX XXX
International: +244 XXX XXX XXX
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Luanda (222) | `222 XXX XXX` | `+244 222 XXX XXX` |
| Other provinces (2XX) | `2XX XXX XXX` | `+244 2XX XXX XXX` |
| Mobile (91X, 92X, 93X, 94X, 99X) | `923 XXX XXX` | `+244 923 XXX XXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+244222123456` | `+244 222 123 456` | `222 123 456` | Luanda — fixed lines begin with 2, followed by the area code |
| mobile | `+244923123456` | `+244 923 123 456` | `923 123 456` | Mobile — 923 is a Unitel range |
| mobile | `+244912345678` | `+244 912 345 678` | `912 345 678` | Mobile — 91X range |

## Notes

- Closed 9-digit plan dialled in full for every call.
- Fixed-line numbers begin with 2 followed by a 1–2 digit geographic area code; mobile numbers begin with 9.
