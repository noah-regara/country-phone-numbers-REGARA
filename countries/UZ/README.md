# Uzbekistan — Phone Number Formats

**ISO 3166-1:** `UZ` / `UZB`  
**Country calling code:** +998  
**Trunk prefix:** none  
**International call prefix:** `00`  
**National significant number:** 9 digits

## Formatting

```
National:      AA XXX XX XX
International: +998 AA XXX XX XX
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Tashkent (71) | `71 XXX XX XX` | `+998 71 XXX XX XX` |
| Other regions (2-digit area codes) | `XX XXX XX XX` | `+998 XX XXX XX XX` |
| Mobile (88, 90, 91, 93, 94, 95, 97, 98, 99) | `90 XXX XX XX` | `+998 90 XXX XX XX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+998711234567` | `+998 71 123 45 67` | `71 123 45 67` | Tashkent — area code 71 |
| mobile | `+998901234567` | `+998 90 123 45 67` | `90 123 45 67` | Mobile — 90 is a Beeline range |
| mobile | `+998971234567` | `+998 97 123 45 67` | `97 123 45 67` | Mobile — 97 range |

## Notes

- Uzbekistan uses a closed 9-digit plan: a 2-digit area or operator code plus a 7-digit subscriber number.
- The Soviet-era 8~10 international prefix has been replaced by 00.
