# Guadeloupe — Phone Number Formats

**ISO 3166-1:** `GP` / `GLP`  
**Country calling code:** +590  
**Trunk prefix:** `0`  
**International call prefix:** `00`  
**National significant number:** 9 digits

## Formatting

```
National:      0590 XX XX XX
International: +590 590 XX XX XX
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Fixed line (0590) | `0590 XX XX XX` | `+590 590 XX XX XX` |
| Mobile (0690, 0691) | `0690 XX XX XX` | `+590 690 XX XX XX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+590590123456` | `+590 590 12 34 56` | `0590 12 34 56` | Guadeloupe fixed — note the 590 appears twice: once as country code, once as the internal area code |
| mobile | `+590690123456` | `+590 690 12 34 56` | `0690 12 34 56` | Mobile — the 0690 range |

## Notes

- Guadeloupe uses the French 10-digit national format with the country code doubling as the internal area code — +590 590 xx xx xx is correct and not a typo.
- Saint Barthélemy and Saint Martin share the +590 country code with Guadeloupe.
- Numbers are written in the French style as pairs.
