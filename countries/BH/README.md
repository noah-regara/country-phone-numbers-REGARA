# Bahrain — Phone Number Formats

**ISO 3166-1:** `BH` / `BHR`  
**Country calling code:** +973  
**Trunk prefix:** none  
**International call prefix:** `00`  
**National significant number:** 8 digits

## Formatting

```
National:      XXXX XXXX
International: +973 XXXX XXXX
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Fixed line — Batelco (17) | `17XX XXXX` | `+973 17XX XXXX` |
| Mobile — Batelco (39, 380–389), Zain (36, 37), stc (34) | `39XX XXXX` | `+973 39XX XXXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+97317123456` | `+973 1712 3456` | `1712 3456` | Fixed line — 17 is Batelco's fixed-line prefix |
| mobile | `+97339123456` | `+973 3912 3456` | `3912 3456` | Mobile — 39 is a Batelco range |
| mobile | `+97336123456` | `+973 3612 3456` | `3612 3456` | Mobile — 36/37 are Zain Bahrain ranges |

## Notes

- Bahrain has no area codes or trunk prefix; all numbers are 8 digits.
- The two digits following a landline prefix loosely indicate region, but the leading pair mainly identifies the operator.
