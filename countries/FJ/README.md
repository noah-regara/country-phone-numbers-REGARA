# Fiji — Phone Number Formats

**ISO 3166-1:** `FJ` / `FJI`  
**Country calling code:** +679  
**Trunk prefix:** none  
**International call prefix:** `00`  
**National significant number:** 7 digits

## Formatting

```
National:      XXX XXXX
International: +679 XXX XXXX
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Fixed line (3, 5, 6) | `33X XXXX` | `+679 33X XXXX` |
| Mobile (2, 7, 8, 9) | `77X XXXX` | `+679 77X XXXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+6793321234` | `+679 332 1234` | `332 1234` | Suva CBD — 3 marks a fixed line, the second digit the locality |
| mobile | `+6797712345` | `+679 771 2345` | `771 2345` | Mobile — 7 is a Digicel Fiji range |

## Notes

- Fiji has no area codes and no trunk prefix; the first digit indicates usage or location.
- The international access prefix is 00 or 052 depending on the carrier.
