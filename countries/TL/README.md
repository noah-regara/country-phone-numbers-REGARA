# Timor-Leste — Phone Number Formats

**ISO 3166-1:** `TL` / `TLS`  
**Country calling code:** +670  
**Trunk prefix:** none  
**International call prefix:** `00`  
**National significant number:** 7 or 8 digits

## Formatting

```
National:      XXX XXXX (fixed) / XXXX XXXX (mobile)
International: +670 XXX XXXX
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Fixed line — Dili (33X) | `33X XXXX` | `+670 33X XXXX` |
| Mobile (73XX–78XX) | `73XX XXXX` | `+670 73XX XXXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+6703301234` | `+670 330 1234` | `330 1234` | Dili — the 33X fixed allocation |
| mobile | `+67073123456` | `+670 7312 3456` | `7312 3456` | Mobile — a 7 was prefixed to mobile numbers, making them 8 digits |

## Notes

- Timor-Leste moved off Indonesia's +62 plan after 1999 and took its own code +670.
- Closed plan: fixed NSNs are 7 digits, mobile NSNs 8.
