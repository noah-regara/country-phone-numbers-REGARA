# Curaçao — Phone Number Formats

**ISO 3166-1:** `CW` / `CUW`  
**Country calling code:** +599  
**Trunk prefix:** none  
**International call prefix:** `00`  
**National significant number:** 8 digits

## Formatting

```
National:      9 XXX XXXX
International: +599 9 XXX XXXX
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Fixed line (9 4XX XXXX, 9 8XX XXXX) | `9 461 XXXX` | `+599 9 461 XXXX` |
| Mobile (9 5XX XXXX, 9 6XX XXXX) | `9 518 XXXX` | `+599 9 518 XXXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+59994611234` | `+599 9 461 1234` | `9 461 1234` | Curaçao — area code 9 plus a 7-digit local number |
| mobile | `+59995181234` | `+599 9 518 1234` | `9 518 1234` | Mobile — the 9 5XX range |

## Notes

- Curaçao retains country code +599, originally assigned to the Netherlands Antilles, with area code 9.
- Sint Maarten left +599 in 2011 to join the NANP as +1 721; Aruba had left earlier for +297.
