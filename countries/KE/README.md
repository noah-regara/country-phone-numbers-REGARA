# Kenya — Phone Number Formats

**ISO 3166-1:** `KE` / `KEN`  
**Country calling code:** +254  
**Trunk prefix:** `0`  
**International call prefix:** `000`  
**National significant number:** 9 digits

## Formatting

```
National:      0AA XXXXXXX (landline) / 07XX XXXXXX (mobile)
International: +254 AA XXXXXXX (trunk 0 dropped)
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Nairobi (020) | `020 XXXXXXX` | `+254 20 XXXXXXX` |
| Other regions (area codes 20–69) | `0XX XXXXXX` | `+254 XX XXXXXX` |
| Mobile (701–799) | `0722 XXXXXX` | `+254 722 XXXXXX` |
| Toll-free | `0800 XXXXXX` | `+254 800 XXXXXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+254201234567` | `+254 20 1234567` | `020 1234567` | Nairobi — area code 20 |
| mobile | `+254722123456` | `+254 722 123456` | `0722 123456` | Mobile — 722 is a Safaricom range |
| toll-free | `+254800123456` | `+254 800 123456` | `0800 123456` | Toll-free within Kenya |

## Notes

- The international access prefix is 000.
- Landline area codes 20–69 map to geographic regions; mobile prefixes 701–799 are nationwide and portable since 2011.
