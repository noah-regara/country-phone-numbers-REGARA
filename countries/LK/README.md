# Sri Lanka — Phone Number Formats

**ISO 3166-1:** `LK` / `LKA`  
**Country calling code:** +94  
**Trunk prefix:** `0`  
**International call prefix:** `00`  
**National significant number:** 9 digits

## Formatting

```
National:      0AA X XXXXXX (fixed) / 0XX XXXXXXX (mobile)
International: +94 AA X XXXXXX (trunk 0 dropped)
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Colombo (011) | `011 X XXXXXX` | `+94 11 X XXXXXX` |
| Other districts (2-digit area codes) | `0XX X XXXXXX` | `+94 XX X XXXXXX` |
| Mobile (070–078) | `077 XXXXXXX` | `+94 77 XXXXXXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+94112123456` | `+94 11 2 123456` | `011 2 123456` | Colombo — area code 011; the digit after it identifies the fixed operator (2 = SLT-Mobitel) |
| mobile | `+94777123456` | `+94 77 7123456` | `077 7123456` | Mobile — 077 is a Dialog Axiata range |
| mobile | `+94712345678` | `+94 71 2345678` | `071 2345678` | Mobile — 071 is an SLT-Mobitel range |

## Notes

- Sri Lankan fixed numbers embed an operator digit between the area code and the 6-digit subscriber number.
- Mobile operator codes fall in the 070–078 range; the NSN is 9 digits for both fixed and mobile.
