# Tuvalu — Phone Number Formats

**ISO 3166-1:** `TV` / `TUV`  
**Country calling code:** +688  
**Trunk prefix:** none  
**International call prefix:** `00`  
**National significant number:** 5 or 6 digits

## Formatting

```
National:      XX XXX
International: +688 XX XXX
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Fixed line — Funafuti (20, 21); other atolls (22–29) | `20 XXX` | `+688 20 XXX` |
| Mobile (90 XXXX) | `90 XXXX` | `+688 90 XXXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+68820123` | `+688 20 123` | `20 123` | Funafuti — atoll code 20 |
| mobile | `+688901234` | `+688 90 1234` | `90 1234` | Mobile — the 90 prepaid range, one digit longer than fixed |

## Notes

- Each of Tuvalu's nine atolls has its own dialling code (20–29), with Funafuti holding two (20 and 21).
- Fixed NSNs are 5 digits and mobile NSNs 6.
