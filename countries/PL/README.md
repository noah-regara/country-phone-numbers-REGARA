# Poland — Phone Number Formats

**ISO 3166-1:** `PL` / `POL`  
**Country calling code:** +48  
**Trunk prefix:** none  
**International call prefix:** `00`  
**National significant number:** 9 digits

## Formatting

```
National:      XX XXX XX XX (geographic) / XXX XXX XXX (mobile)
International: +48 XX XXX XX XX
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Warsaw (22), Kraków (12), Gdańsk (58) | `22 XXX XX XX` | `+48 22 XXX XX XX` |
| Mobile (45x, 5xx, 6xx, 7xx, 88x) | `501 234 567` | `+48 501 234 567` |
| Freephone | `800 XXX XXX` | `+48 800 XXX XXX` |
| Premium rate | `70X XXX XXX` | `+48 70X XXX XXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+48221234567` | `+48 22 123 45 67` | `22 123 45 67` | Warsaw — area code 22 |
| fixed-line | `+48121234567` | `+48 12 123 45 67` | `12 123 45 67` | Kraków — area code 12 |
| mobile | `+48501234567` | `+48 501 234 567` | `501 234 567` | Mobile — 50x is an allocated Polish mobile range |
| toll-free | `+48800123456` | `+48 800 123 456` | `800 123 456` | Freephone (free for callers in Poland) |

## Notes

- Poland abolished the trunk prefix 0 on 2009-09-30 and moved to a closed 9-digit plan; the full number is dialled for every call.
- Poland is one of only a handful of EU states (with Spain, Portugal, Denmark and others) to have dropped the trunk prefix entirely.
- Geographic numbers are conventionally grouped 2-3-2-2; mobile numbers 3-3-3.
