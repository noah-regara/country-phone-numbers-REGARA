# New Caledonia — Phone Number Formats

**ISO 3166-1:** `NC` / `NCL`  
**Country calling code:** +687  
**Trunk prefix:** none  
**International call prefix:** `00`  
**National significant number:** 6 digits

## Formatting

```
National:      XX XX XX
International: +687 XX XX XX
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Fixed line (20–29, 30–35, 41–47) | `20 XX XX` | `+687 20 XX XX` |
| Mobile (70, 73–79, 80–87, 89–99) | `70 XX XX` | `+687 70 XX XX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+687201234` | `+687 20 12 34` | `20 12 34` | Fixed line — the 2x range serves the PSTN |
| mobile | `+687701234` | `+687 70 12 34` | `70 12 34` | Mobile — the 7x–9x ranges (Mobilis) |

## Notes

- New Caledonia keeps a short 6-digit plan with no trunk prefix or area codes.
- Leading digits classify the service: 2–4 fixed, 7–9 mobile.
