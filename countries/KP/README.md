# Korea, Democratic People's Republic of — Phone Number Formats

**ISO 3166-1:** `KP` / `PRK`  
**Country calling code:** +850  
**Trunk prefix:** `0`  
**International call prefix:** `00`  
**National significant number:** variable

## Formatting

```
National:      0A XXX XXXX (fixed) / 019X XXXXXXX (mobile)
International: +850 A XXX XXXX (trunk 0 dropped)
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Pyongyang (2) | `02 XXX XXXX` | `+850 2 XXX XXXX` |
| Provincial (2-digit area codes) | `0XX XXXXXX` | `+850 XX XXXXXX` |
| Mobile (019X) | `019X XXXXXXX` | `+850 19X XXXXXXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+85023811234` | `+850 2 381 1234` | `02 381 1234` | Pyongyang — area code 2; the 381 block includes lines reachable from abroad |
| mobile | `+8501921234567` | `+850 192 1234567` | `0192 1234567` | Mobile — the 019X ranges (Koryolink) |

## Notes

- International connectivity is heavily restricted: most calls into North Korea require operator assistance via +850 2 18111, and only selected numbers can be dialled directly.
- Calls between North and South Korea are banned outside the former Kaesong Industrial Region.
- NSN length varies — roughly 8 digits for Pyongyang landlines and 10 for mobile numbers.
