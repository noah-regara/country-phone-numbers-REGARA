# Uganda — Phone Number Formats

**ISO 3166-1:** `UG` / `UGA`  
**Country calling code:** +256  
**Trunk prefix:** `0`  
**International call prefix:** `000`  
**National significant number:** 9 digits

## Formatting

```
National:      0AA XXX XXXX
International: +256 AA XXX XXXX (trunk 0 dropped)
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Kampala (041) | `041 XXX XXXX` | `+256 41 XXX XXXX` |
| Other regions (2-digit area codes) | `0XX XXX XXXX` | `+256 XX XXX XXXX` |
| Mobile (07X) | `077 XXX XXXX` | `+256 77 XXX XXXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+256411234567` | `+256 41 123 4567` | `041 123 4567` | Kampala — area code 41 |
| mobile | `+256771234567` | `+256 77 123 4567` | `077 123 4567` | Mobile — 77 is an MTN Uganda range |
| mobile | `+256701234567` | `+256 70 123 4567` | `070 123 4567` | Mobile — 70 range |

## Notes

- Closed 9-digit plan requiring the full number for domestic calls.
- The international access prefix is 000.
