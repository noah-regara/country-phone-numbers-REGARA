# Togo — Phone Number Formats

**ISO 3166-1:** `TG` / `TGO`  
**Country calling code:** +228  
**Trunk prefix:** none  
**International call prefix:** `00`  
**National significant number:** 8 digits

## Formatting

```
National:      XX XX XX XX
International: +228 XX XX XX XX
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Fixed line — Lomé (22) | `22 XX XX XX` | `+228 22 XX XX XX` |
| Mobile — Togocel (70–73, 90–93), Moov (78, 79, 96–99) | `70 XX XX XX` | `+228 70 XX XX XX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+22822123456` | `+228 22 12 34 56` | `22 12 34 56` | Lomé — area code 22 |
| mobile | `+22870123456` | `+228 70 12 34 56` | `70 12 34 56` | Mobile — 70 is a Togocel range |

## Notes

- Closed 8-digit plan with no trunk prefix; numbers are written in pairs in the French style.
- Mobile codes begin 7x or 9x with the second digit identifying the operator.
