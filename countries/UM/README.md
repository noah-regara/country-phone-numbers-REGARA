# United States Minor Outlying Islands — Phone Number Formats

**ISO 3166-1:** `UM` / `UMI`  
**Country calling code:** +1  
**Trunk prefix:** `1`  
**International call prefix:** `011`  
**National significant number:** variable

## Formatting

```
National:      no dedicated numbering
International: military circuits reached through US ranges
```

## Examples

_No public numbering is assigned to this territory — see the notes below._

## Notes

- The United States Minor Outlying Islands are a statistical grouping of nine uninhabited or minimally staffed islands (Baker, Howland, Jarvis, Johnston Atoll, Kingman Reef, Midway, Navassa, Palmyra, Wake). None has a civilian numbering plan.
- Wake Island and Midway Atoll, the only ones with any regular staffing, are reached through US military circuits historically routed via the Hawaii area code +1 808.
- There is no ISO-territory-specific country code or area code; ISO 3166-1 assigns UM for statistical purposes only.
