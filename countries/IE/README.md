# Ireland — Phone Number Formats

**ISO 3166-1:** `IE` / `IRL`  
**Country calling code:** +353  
**Trunk prefix:** `0`  
**International call prefix:** `00`  
**National significant number:** 7 or 8 or 9 or 10 digits

## Formatting

```
National:      0AA XXX XXXX (open plan, variable)
International: +353 AA XXX XXXX (trunk 0 dropped)
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Dublin | `01 XXX XXXX` | `+353 1 XXX XXXX` |
| Other geographic (Cork 021, Galway 091) | `0XX XXX XXXX` | `+353 XX XXX XXXX` |
| Mobile | `08X XXX XXXX` | `+353 8X XXX XXXX` |
| Freephone | `1800 XXX XXX` | `+353 1800 XXX XXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+35312345678` | `+353 1 234 5678` | `01 234 5678` | Dublin — area code 01 |
| fixed-line | `+353214123456` | `+353 21 412 3456` | `021 412 3456` | Cork — area code 021 |
| mobile | `+353871234567` | `+353 87 123 4567` | `087 123 4567` | Mobile — 087 originally Vodafone |
| toll-free | `+3531800123456` | `+353 1800 123 456` | `1800 123 456` | Freephone — dialled without a trunk 0 |

## Notes

- Ireland uses an open numbering plan: area codes are 1–3 digits after the trunk 0 and subscriber numbers vary, so NSN length ranges from 7 to 9 digits (10 for 1800 freephone).
- Freephone (1800) and shared-cost (1850/0818) numbers are dialled without the trunk 0.
