# Libya — Phone Number Formats

**ISO 3166-1:** `LY` / `LBY`  
**Country calling code:** +218  
**Trunk prefix:** `0`  
**International call prefix:** `00`  
**National significant number:** 8 or 9 digits

## Formatting

```
National:      0AA XXX XXXX
International: +218 AA XXX XXXX (trunk 0 dropped)
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Tripoli (021) | `021 XXX XXXX` | `+218 21 XXX XXXX` |
| Benghazi (061) | `061 XXX XXXX` | `+218 61 XXX XXXX` |
| Mobile — Al-Madar (91, 93), Libyana (92, 94), LibyaPhone (95) | `091 XXX XXXX` | `+218 91 XXX XXXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+218211234567` | `+218 21 123 4567` | `021 123 4567` | Tripoli — area code 21 |
| mobile | `+218911234567` | `+218 91 123 4567` | `091 123 4567` | Mobile — 91/93 are Al-Madar ranges |
| mobile | `+218921234567` | `+218 92 123 4567` | `092 123 4567` | Mobile — 92/94 are Libyana ranges |

## Notes

- The trunk prefix 0 is dropped and replaced by +218 when dialling from abroad.
- Mobile prefixes identify the operator: 91/93 Al-Madar, 92/94 Libyana, 95 LibyaPhone (LTT).
