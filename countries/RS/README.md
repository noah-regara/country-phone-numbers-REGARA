# Serbia — Phone Number Formats

**ISO 3166-1:** `RS` / `SRB`  
**Country calling code:** +381  
**Trunk prefix:** `0`  
**International call prefix:** `00`  
**National significant number:** 8 or 9 digits

## Formatting

```
National:      0AA XXX XX XX (open plan)
International: +381 AA XXX XX XX (trunk 0 dropped)
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Belgrade (011) | `011 XXX XX XX` | `+381 11 XXX XX XX` |
| Novi Sad (021), Niš (018) | `021 XXX XXX` | `+381 21 XXX XXX` |
| Mobile (060–069) | `064 XXX XXXX` | `+381 64 XXX XXXX` |
| Freephone | `0800 XXX XXX` | `+381 800 XXX XXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+381111234567` | `+381 11 123 45 67` | `011 123 45 67` | Belgrade — area code 011 covers the city and surrounding municipalities |
| fixed-line | `+38121123456` | `+381 21 123 456` | `021 123 456` | Novi Sad — area code 021 |
| mobile | `+381641234567` | `+381 64 123 4567` | `064 123 4567` | Mobile — the 060–069 range is shared by A1, Yettel and mts |
| toll-free | `+381800123456` | `+381 800 123 456` | `0800 123 456` | Freephone |

## Notes

- Serbia uses an open numbering plan; area codes are largely unchanged from the Yugoslav era, and subscriber numbers run 6–7 digits.
- The international prefix changed from 99 to 00 on 2008-04-01.
