# Namibia — Phone Number Formats

**ISO 3166-1:** `NA` / `NAM`  
**Country calling code:** +264  
**Trunk prefix:** `0`  
**International call prefix:** `00`  
**National significant number:** 9 digits

## Formatting

```
National:      0AA XXX XXXX
International: +264 AA XXX XXXX (trunk 0 dropped)
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Windhoek (061) | `061 XXX XXXX` | `+264 61 XXX XXXX` |
| Other regions (2-digit area codes) | `0XX XXX XXXX` | `+264 XX XXX XXXX` |
| Mobile — MTC (081), MTN (084), tn mobile (085) | `081 XXX XXXX` | `+264 81 XXX XXXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+264611234567` | `+264 61 123 4567` | `061 123 4567` | Windhoek — area code 061 |
| mobile | `+264811234567` | `+264 81 123 4567` | `081 123 4567` | Mobile — 081 is an MTC range |

## Notes

- Namibia's plan was originally part of South Africa's; the ITU allocated +264 in the late 1960s and it came into full use after independence in 1990.
- The international access prefix changed from 09 to 00.
