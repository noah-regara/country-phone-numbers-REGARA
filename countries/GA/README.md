# Gabon — Phone Number Formats

**ISO 3166-1:** `GA` / `GAB`  
**Country calling code:** +241  
**Trunk prefix:** none  
**International call prefix:** `00`  
**National significant number:** 8 digits

## Formatting

```
National:      0X XX XX XX
International: +241 0X XX XX XX (the leading 0 is kept)
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Fixed line — Gabon Telecom (01) | `01 XX XX XX` | `+241 01 XX XX XX` |
| Mobile — Libertis, Airtel, Moov (02–07) | `02 XX XX XX` | `+241 02 XX XX XX` |
| Value-added services (8) | `8X XX XX XX` | `+241 8X XX XX XX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+24101441234` | `+241 01 44 12 34` | `01 44 12 34` | Libreville — 01 is Gabon Telecom's fixed prefix, retained when dialling from abroad |
| mobile | `+24102123456` | `+241 02 12 34 56` | `02 12 34 56` | Mobile — 02 is a Libertis range |

## Notes

- Gabon is one of the countries where the leading 0 is part of the number rather than a trunk prefix, so it must be dialled from abroad.
- The plan was revised in 2012 and again on 2019-07-12.
