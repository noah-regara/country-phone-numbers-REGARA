# Bonaire, Sint Eustatius and Saba — Phone Number Formats

**ISO 3166-1:** `BQ` / `BES`  
**Country calling code:** +599  
**Trunk prefix:** none  
**International call prefix:** `00`  
**National significant number:** 7 digits

## Formatting

```
National:      XXX XXXX
International: +599 XXX XXXX
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Bonaire (7XX XXXX) | `717 XXXX` | `+599 717 XXXX` |
| Saba (416 XXXX) | `416 XXXX` | `+599 416 XXXX` |
| Sint Eustatius (318 XXXX) | `318 XXXX` | `+599 318 XXXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+5997171234` | `+599 717 1234` | `717 1234` | Bonaire — the 7XX range |
| fixed-line | `+5994161234` | `+599 416 1234` | `416 1234` | Saba — the 416 range |
| fixed-line | `+5993181234` | `+599 318 1234` | `318 1234` | Sint Eustatius — the 318 range |

## Notes

- The Caribbean Netherlands (Bonaire, Sint Eustatius and Saba) share +599 with Curaçao but use different leading digits rather than a separate country code.
- The three islands are distinguished only by their number blocks, so the specific island cannot be inferred from the country code alone.
- Local numbers were standardised to seven digits in the 1999 reforms.
