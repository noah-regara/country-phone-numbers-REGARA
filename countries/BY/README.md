# Belarus — Phone Number Formats

**ISO 3166-1:** `BY` / `BLR`  
**Country calling code:** +375  
**Trunk prefix:** `8`  
**International call prefix:** `810`  
**National significant number:** 9 digits

## Formatting

```
National:      8 0AA XXX XX XX (trunk prefix 8, not 0)
International: +375 AA XXX XX XX
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Minsk (17) | `8 017 XXX XX XX` | `+375 17 XXX XX XX` |
| Other geographic (152 Grodno, 162 Brest, 212 Vitebsk) | `8 0162 XX XX XX` | `+375 162 XX XX XX` |
| Mobile (25, 29, 33, 44) | `8 029 XXX XX XX` | `+375 29 XXX XX XX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+375172123456` | `+375 17 212 34 56` | `8 017 212 34 56` | Minsk — area code 17 |
| mobile | `+375291234567` | `+375 29 123 45 67` | `8 029 123 45 67` | Mobile — 29 is shared by A1 and MTS Belarus |
| mobile | `+375331234567` | `+375 33 123 45 67` | `8 033 123 45 67` | Mobile — 33 range |

## Notes

- Belarus retains the Soviet-era trunk prefix 8 rather than the European 0, and uses 810 as the international access code.
- Belarus took country code +375 in 1995, replacing the Soviet +7.
- Area codes derive from the old 3-digit USSR codes with the leading zero removed.
