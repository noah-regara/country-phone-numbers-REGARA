# French Polynesia — Phone Number Formats

**ISO 3166-1:** `PF` / `PYF`  
**Country calling code:** +689  
**Trunk prefix:** none  
**International call prefix:** `00`  
**National significant number:** 8 digits

## Formatting

```
National:      XX XX XX XX
International: +689 XX XX XX XX
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Fixed line — OPT (40–49) | `40 XX XX XX` | `+689 40 XX XX XX` |
| Mobile — VINI (87), VITI (88), Pacific Mobile Telecom (89) | `87 XX XX XX` | `+689 87 XX XX XX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+68940123456` | `+689 40 12 34 56` | `40 12 34 56` | Fixed line — the 40–49 range is operated by OPT |
| mobile | `+68987123456` | `+689 87 12 34 56` | `87 12 34 56` | Mobile — 87 is a VINI range |

## Notes

- French Polynesia has used a closed 8-digit plan since 2014, replacing the earlier 6-digit numbers.
- No trunk prefix; numbers are written in pairs in the French style.
