# Kiribati — Phone Number Formats

**ISO 3166-1:** `KI` / `KIR`  
**Country calling code:** +686  
**Trunk prefix:** none  
**International call prefix:** `00`  
**National significant number:** 8 digits

## Formatting

```
National:      XXXX XXXX
International: +686 XXXX XXXX
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Fixed line — South Tarawa (65X XXXXX) | `6502 XXXX` | `+686 6502 XXXX` |
| Mobile (63X XXXXX) | `6300 XXXX` | `+686 6300 XXXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+68665021500` | `+686 6502 1500` | `6502 1500` | Bairiki, South Tarawa — the 650 geographic block |
| mobile | `+68663005000` | `+686 6300 5000` | `6300 5000` | Mobile — the 630 cellular block |

## Notes

- Kiribati expanded from 5-digit to 8-digit numbers in a phased migration between 2013 and 2018.
- No trunk prefix or area codes.
