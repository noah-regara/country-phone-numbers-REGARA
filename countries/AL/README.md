# Albania — Phone Number Formats

**ISO 3166-1:** `AL` / `ALB`  
**Country calling code:** +355  
**Trunk prefix:** `0`  
**International call prefix:** `00`  
**National significant number:** 8 or 9 digits

## Formatting

```
National:      0A XXX XXXX (Tirana) / 0AA XXX XXX (elsewhere)
International: +355 A XXX XXXX (trunk 0 dropped)
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Tirana (04) | `04 XXX XXXX` | `+355 4 XXX XXXX` |
| Other geographic | `0XX XXX XXX` | `+355 XX XXX XXX` |
| Mobile (066–069) | `069 XXX XXXX` | `+355 69 XXX XXXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+35542345678` | `+355 4 234 5678` | `04 234 5678` | Tirana — area code 4 |
| fixed-line | `+35533123456` | `+355 33 123 456` | `033 123 456` | Durrës region — 2-digit area code |
| mobile | `+355691234567` | `+355 69 123 4567` | `069 123 4567` | Mobile — 069 is a Vodafone Albania range; 067/068 One Albania |

## Notes

- Albania added a digit to local numbers nationwide in September 2008, moving to the current 8-digit standard for fixed lines.
- Mobile NSNs are 9 digits; fixed-line NSNs are 8.
