# Türkiye — Phone Number Formats

**ISO 3166-1:** `TR` / `TUR`  
**Country calling code:** +90  
**Trunk prefix:** `0`  
**International call prefix:** `00`  
**National significant number:** 10 digits

## Formatting

```
National:      0 (AAA) XXX XX XX
International: +90 AAA XXX XX XX (trunk 0 dropped)
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Istanbul — European side (212), Asian side (216) | `0212 XXX XX XX` | `+90 212 XXX XX XX` |
| Ankara (312), İzmir (232) | `0312 XXX XX XX` | `+90 312 XXX XX XX` |
| Mobile (5XX) | `0530 XXX XX XX` | `+90 530 XXX XX XX` |
| Freephone | `0800 XXX XX XX` | `+90 800 XXX XX XX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+902121234567` | `+90 212 123 45 67` | `0212 123 45 67` | Istanbul, European side — area code 212 |
| fixed-line | `+903121234567` | `+90 312 123 45 67` | `0312 123 45 67` | Ankara — area code 312 |
| mobile | `+905301234567` | `+90 530 123 45 67` | `0530 123 45 67` | Mobile — 530–539 are Turkcell ranges; all mobiles begin with 5 |
| toll-free | `+908001234567` | `+90 800 123 45 67` | `0800 123 45 67` | Freephone |

## Notes

- Closed plan: every province has a 3-digit area code and a 7-digit local number, giving a uniform 10-digit NSN.
- Istanbul is the only province with two area codes — 212 for the European side and 216 for the Asian side.
- Northern Cyprus is integrated into the Turkish plan as +90 392.
