# Uruguay — Phone Number Formats

**ISO 3166-1:** `UY` / `URY`  
**Country calling code:** +598  
**Trunk prefix:** `0`  
**International call prefix:** `00`  
**National significant number:** 8 digits

## Formatting

```
National:      XXXX XXXX (fixed) / 9X XXX XXX (mobile)
International: +598 XXXX XXXX
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Montevideo fixed (2) | `2XXX XXXX` | `+598 2XXX XXXX` |
| Fixed outside Montevideo (4) | `4XXX XXXX` | `+598 4XXX XXXX` |
| Mobile (9X) | `09X XXX XXX` | `+598 9X XXX XXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+59822045199` | `+598 2204 5199` | `2204 5199` | Montevideo — the 2 prefix identifies the metropolitan area |
| mobile | `+59899123456` | `+598 99 123 456` | `099 123 456` | Mobile — 99 was an Antel range; portability means prefixes no longer identify the operator |
| fixed-line | `+59843123456` | `+598 4312 3456` | `4312 3456` | Fixed line outside Montevideo — the 4 prefix |

## Notes

- Uruguay abolished area codes on 2010-08-29 and moved to a flat 8-digit NSN.
- The trunk prefix 0 shows up on mobile numbers, which are written and dialled domestically as 09X XXX XXX; the NSN is the 8 digits after it (9X XXX XXX). Fixed lines are dialled as a plain 8 digits with no prefix.
- Number portability means the leading digits of a mobile number no longer indicate the operator.
