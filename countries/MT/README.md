# Malta — Phone Number Formats

**ISO 3166-1:** `MT` / `MLT`  
**Country calling code:** +356  
**Trunk prefix:** none  
**International call prefix:** `00`  
**National significant number:** 8 digits

## Formatting

```
National:      XXXX XXXX
International: +356 XXXX XXXX
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Fixed line (21, 22, 27) | `21XX XXXX` | `+356 21XX XXXX` |
| Mobile (79, 99, 77, 98) | `99XX XXXX` | `+356 99XX XXXX` |
| Freephone | `8007 XXXX` | `+356 8007 XXXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+35621234567` | `+356 2123 4567` | `2123 4567` | Fixed line — 21 is a GO range |
| mobile | `+35699234567` | `+356 9923 4567` | `9923 4567` | Mobile — 99 range (replaced the old 09 prefix in 2002) |
| mobile | `+35679123456` | `+356 7912 3456` | `7912 3456` | Mobile — 79 range |

## Notes

- Malta runs a closed 8-digit plan with no trunk prefix or area codes; numbers are conventionally written as two groups of four.
- All numbers were expanded from 6–7 digits to 8 digits during the 2001–2002 reform.
