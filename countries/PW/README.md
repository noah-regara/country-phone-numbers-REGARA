# Palau — Phone Number Formats

**ISO 3166-1:** `PW` / `PLW`  
**Country calling code:** +680  
**Trunk prefix:** none  
**International call prefix:** `011`  
**National significant number:** 7 digits

## Formatting

```
National:      XXX XXXX
International: +680 XXX XXXX
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Fixed line — PNCC, Koror (488) | `488 XXXX` | `+680 488 XXXX` |
| Mobile — PT Waves (880), PNCC, PMC | `880 XXXX` | `+680 880 XXXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+6804881234` | `+680 488 1234` | `488 1234` | Koror State — the 488 PNCC exchange |
| mobile | `+6808801234` | `+680 880 1234` | `880 1234` | Mobile — the 880 PT Waves range |

## Notes

- Palau uses 7-digit numbers with a 3-digit area or operator code plus a 4-digit line number.
- The international access prefix is 011 (also 012), inherited from US practice, though Palau is not in the NANP.
