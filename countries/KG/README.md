# Kyrgyzstan — Phone Number Formats

**ISO 3166-1:** `KG` / `KGZ`  
**Country calling code:** +996  
**Trunk prefix:** `0`  
**International call prefix:** `00`  
**National significant number:** 9 digits

## Formatting

```
National:      0AAA XXXXXX
International: +996 AAA XXXXXX (trunk 0 dropped)
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Bishkek (312) | `0312 XXXXXX` | `+996 312 XXXXXX` |
| Other regions (3-digit area codes) | `0XXX XXXXXX` | `+996 XXX XXXXXX` |
| Mobile (70X, 55X, 77X, 99X) | `0701 XXXXXX` | `+996 701 XXXXXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+996312501234` | `+996 312 501234` | `0312 501234` | Bishkek — area code 312 (KyrgyzTelecom) |
| mobile | `+996701123456` | `+996 701 123456` | `0701 123456` | Mobile — 70X is a Nur Telecom (O!) range |

## Notes

- Kyrgyzstan uses the European-style trunk prefix 0 and 00 international access rather than the Soviet 8/8~10 convention still used by some neighbours.
- Closed 9-digit plan: 3-digit area or operator code plus 6-digit subscriber number.
