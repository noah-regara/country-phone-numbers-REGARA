# Gibraltar — Phone Number Formats

**ISO 3166-1:** `GI` / `GIB`  
**Country calling code:** +350  
**Trunk prefix:** none  
**International call prefix:** `00`  
**National significant number:** 8 digits

## Formatting

```
National:      XXX XXXXX
International: +350 XXX XXXXX
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Fixed line (Gibtelecom, 200xxxxx) | `200 XXXXX` | `+350 200 XXXXX` |
| Mobile (5xxxxxxx) | `5XX XXXХХ` | `+350 5XX XXXXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+35020052200` | `+350 200 52200` | `200 52200` | Gibtelecom fixed line — '200' was prepended to the legacy 5-digit number |
| mobile | `+35054123456` | `+350 541 23456` | `541 23456` | Mobile — 5x ranges |

## Notes

- Gibraltar moved to 8-digit numbers on 2008-10-01. Legacy 5-digit landlines were preserved by prefixing '200'.
- No trunk prefix or area codes; the full 8-digit number is always dialled.
