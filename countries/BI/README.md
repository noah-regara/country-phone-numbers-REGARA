# Burundi — Phone Number Formats

**ISO 3166-1:** `BI` / `BDI`  
**Country calling code:** +257  
**Trunk prefix:** none  
**International call prefix:** `00`  
**National significant number:** 8 digits

## Formatting

```
National:      XX XX XXXX
International: +257 XX XX XXXX
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Fixed line — Bujumbura (2220–2229) | `22 20 XXXX` | `+257 22 20 XXXX` |
| Mobile — Onatel (77), Econet/Lumitel and others (61–79) | `77 XX XXXX` | `+257 77 XX XXXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+25722201234` | `+257 2220 1234` | `2220 1234` | Bujumbura — the 2220 block serves the capital |
| mobile | `+25777125678` | `+257 7712 5678` | `7712 5678` | Mobile — 77 is an Onatel GSM range |

## Notes

- Closed 8-digit plan with no trunk prefix.
- Mobile blocks fall in the 61–79 range across Onatel, Lumitel, Smart and other operators; the regulator is ARCT.
