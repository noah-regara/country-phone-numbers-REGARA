# Saudi Arabia — Phone Number Formats

**ISO 3166-1:** `SA` / `SAU`  
**Country calling code:** +966  
**Trunk prefix:** `0`  
**International call prefix:** `00`  
**National significant number:** 9 or 10 digits

## Formatting

```
National:      0AA XXX XXXX
International: +966 AA XXX XXXX (trunk 0 dropped)
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Riyadh (011) | `011 XXX XXXX` | `+966 11 XXX XXXX` |
| Western region incl. Jeddah (012), Eastern Province (013) | `012 XXX XXXX` | `+966 12 XXX XXXX` |
| Mobile (050, 053, 055 STC; 054, 056 Mobily; 058, 059 Zain) | `050 XXX XXXX` | `+966 50 XXX XXXX` |
| Toll-free | `800 XXX XXXX` | `+966 800 XXX XXXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+966111234567` | `+966 11 123 4567` | `011 123 4567` | Riyadh — area code 011 |
| fixed-line | `+966121234567` | `+966 12 123 4567` | `012 123 4567` | Jeddah and the western region — area code 012 |
| mobile | `+966501234567` | `+966 50 123 4567` | `050 123 4567` | Mobile — 050 is an STC range |
| toll-free | `+9668001234567` | `+966 800 123 4567` | `800 123 4567` | Toll-free — 10-digit NSN, longer than the 9-digit norm |

## Notes

- Saudi area codes were expanded to three digits (011, 012, 013…) in a 2013 renumbering.
- Mobile prefixes map to operators: 050/053/055 STC, 054/056 Mobily, 058/059 Zain.
