# South Africa — Phone Number Formats

**ISO 3166-1:** `ZA` / `ZAF`  
**Country calling code:** +27  
**Trunk prefix:** `0`  
**International call prefix:** `00`  
**National significant number:** 9 digits

## Formatting

```
National:      0AA XXX XXXX
International: +27 AA XXX XXXX (trunk 0 dropped)
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Johannesburg / Gauteng (011) | `011 XXX XXXX` | `+27 11 XXX XXXX` |
| Cape Town / Western Cape (021), Durban / KZN (031) | `021 XXX XXXX` | `+27 21 XXX XXXX` |
| Mobile (060–069, 071–079, 081–084) | `082 XXX XXXX` | `+27 82 XXX XXXX` |
| Toll-free | `0800 XXX XXX` | `+27 800 XXX XXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+27111234567` | `+27 11 123 4567` | `011 123 4567` | Johannesburg — area code 011 |
| fixed-line | `+27211234567` | `+27 21 123 4567` | `021 123 4567` | Cape Town — area code 021 |
| mobile | `+27821234567` | `+27 82 123 4567` | `082 123 4567` | Mobile — 082 is a Vodacom range |
| toll-free | `+27800123456` | `+27 800 123 456` | `0800 123 456` | Toll-free |

## Notes

- South Africa moved to a closed numbering plan on 2007-01-16: the full 10-digit national form (trunk 0 + 9-digit NSN) is required even for local calls.
- Administered by ICASA.
