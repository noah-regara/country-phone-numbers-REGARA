# Georgia — Phone Number Formats

**ISO 3166-1:** `GE` / `GEO`  
**Country calling code:** +995  
**Trunk prefix:** `0`  
**International call prefix:** `00`  
**National significant number:** 9 digits

## Formatting

```
National:      0AA XXX XXXX
International: +995 AA XXX XXXX (trunk 0 dropped)
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Tbilisi (32) | `0 32 2XX XXXX` | `+995 32 2XX XXXX` |
| Eastern Georgia (3xx), Western Georgia (4xx) | `0 4XX XX XXXX` | `+995 4XX XX XXXX` |
| Mobile (5XX) | `0 5XX XXX XXX` | `+995 5XX XXX XXX` |
| Fixed wireless (7XX) | `0 7XX XXX XXX` | `+995 7XX XXX XXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+995322123456` | `+995 32 212 3456` | `0 32 212 3456` | Tbilisi — area code 32; Tbilisi subscriber numbers begin with 2 |
| mobile | `+995595123456` | `+995 595 123 456` | `0 595 123 456` | Mobile — 595 is a MagtiCom range |
| mobile | `+995551123456` | `+995 551 123 456` | `0 551 123 456` | Mobile — all Georgian mobile prefixes begin with 5 |

## Notes

- Closed 9-digit plan. Geographic numbers begin with 3 (eastern Georgia) or 4 (western Georgia); mobile numbers begin with 5.
- A leading 5 was added to all mobile prefixes on 2011-06-20 to separate them cleanly from geographic ranges.
