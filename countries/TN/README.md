# Tunisia — Phone Number Formats

**ISO 3166-1:** `TN` / `TUN`  
**Country calling code:** +216  
**Trunk prefix:** none  
**International call prefix:** `00`  
**National significant number:** 8 digits

## Formatting

```
National:      XX XXX XXX
International: +216 XX XXX XXX
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Fixed line — Tunis (7X), other governorates | `7X XXX XXX` | `+216 7X XXX XXX` |
| Mobile — Tunisie Telecom (9X), Ooredoo (2X), Orange (5X) | `9X XXX XXX` | `+216 9X XXX XXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+21670123456` | `+216 70 123 456` | `70 123 456` | Tunis governorate — 7X fixed range |
| mobile | `+21691234567` | `+216 91 234 567` | `91 234 567` | Mobile — 9X is a Tunisie Telecom range |
| mobile | `+21620123456` | `+216 20 123 456` | `20 123 456` | Mobile — 2X is an Ooredoo range |

## Notes

- Closed 8-digit plan with no trunk prefix; the same digits are dialled at home and abroad after +216.
- The leading digit encodes service and operator rather than geography for mobile ranges.
