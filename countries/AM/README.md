# Armenia — Phone Number Formats

**ISO 3166-1:** `AM` / `ARM`  
**Country calling code:** +374  
**Trunk prefix:** `0`  
**International call prefix:** `00`  
**National significant number:** 8 digits

## Formatting

```
National:      0AA XXXXXX
International: +374 AA XXXXXX (trunk 0 dropped)
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Yerevan (10, 11, 12, 15) | `0 10 XXXXXX` | `+374 10 XXXXXX` |
| Other regions (2-digit destination codes) | `0 XX XXXXXX` | `+374 XX XXXXXX` |
| Mobile (91, 93, 94, 95, 96, 98, 99, 77) | `0 91 XXXXXX` | `+374 91 XXXXXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+37410123456` | `+374 10 123456` | `0 10 123456` | Yerevan — destination codes 10, 11, 12 and 15 |
| mobile | `+37491123456` | `+374 91 123456` | `0 91 123456` | Mobile — 91, 93, 95, 96 and 99 are Team/Viva ranges |
| mobile | `+37477123456` | `+374 77 123456` | `0 77 123456` | Mobile — 77 range |

## Notes

- Closed 8-digit plan: a 2-digit destination code plus a 6-digit subscriber number.
- The trunk prefix 0 is used domestically and dropped when dialling from abroad.
