# Hong Kong — Phone Number Formats

**ISO 3166-1:** `HK` / `HKG`  
**Country calling code:** +852  
**Trunk prefix:** none  
**International call prefix:** `001`  
**National significant number:** 8 digits

## Formatting

```
National:      XXXX XXXX
International: +852 XXXX XXXX
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Fixed line (2, 3) | `2XXX XXXX` | `+852 2XXX XXXX` |
| Mobile (4, 5, 6, 7, 9) | `5XXX XXXX` | `+852 5XXX XXXX` |
| Toll-free | `800X XXXX` | `+852 800X XXXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+85221234567` | `+852 2123 4567` | `2123 4567` | Fixed line — 2 and 3 prefixes |
| fixed-line | `+85231234567` | `+852 3123 4567` | `3123 4567` | Fixed line — 3 prefix, generally newer allocations |
| mobile | `+85251234567` | `+852 5123 4567` | `5123 4567` | Mobile — 4, 5, 6, 7 and 9 prefixes |

## Notes

- Hong Kong abolished area codes at the end of 1989; all numbers are a flat 8 digits with no trunk prefix.
- The international access prefix is 001, not 00.
- Hong Kong keeps its own country code +852 separate from mainland China's +86; calls between them are international.
