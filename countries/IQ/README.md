# Iraq — Phone Number Formats

**ISO 3166-1:** `IQ` / `IRQ`  
**Country calling code:** +964  
**Trunk prefix:** `0`  
**International call prefix:** `00`  
**National significant number:** variable

## Formatting

```
National:      0A XXXXXXX (landline) / 07XX XXX XXXX (mobile)
International: +964 A XXXXXXX (trunk 0 dropped)
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Baghdad (1) | `01 XXXXXXX` | `+964 1 XXXXXXX` |
| Governorates (2-digit area codes) | `0XX XXXXXX` | `+964 XX XXXXXX` |
| Mobile (75X Korek, 77X Asiacell, 78X/79X Zain) | `0751 234 5678` | `+964 751 234 5678` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+96412345678` | `+964 1 234 5678` | `01 234 5678` | Baghdad — area code 1; Baghdad has 7-digit subscriber numbers where most governorates have 6 |
| mobile | `+9647512345678` | `+964 751 234 5678` | `0751 234 5678` | Mobile — 75X is a Korek Telecom range |
| mobile | `+9647712345678` | `+964 771 234 5678` | `0771 234 5678` | Mobile — 77X is an Asiacell range |

## Notes

- Area codes are 1–2 digits and subscriber numbers 6–7, so landline NSN length varies.
- Mobile numbers use a 3-digit operator code plus 7 digits, giving a 10-digit NSN.
