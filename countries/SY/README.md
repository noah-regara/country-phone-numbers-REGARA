# Syrian Arab Republic — Phone Number Formats

**ISO 3166-1:** `SY` / `SYR`  
**Country calling code:** +963  
**Trunk prefix:** `0`  
**International call prefix:** `00`  
**National significant number:** 9 digits

## Formatting

```
National:      0AA XXXXXXX
International: +963 AA XXXXXXX (trunk 0 dropped)
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Damascus (11) | `011 XXXXXXX` | `+963 11 XXXXXXX` |
| Aleppo (21), Homs (31), Latakia (41), Al-Hasakah (52) | `021 XXXXXXX` | `+963 21 XXXXXXX` |
| Mobile — Syriatel (93, 98, 99), MTN Syria (94, 95, 96) | `093X XXXXXX` | `+963 93X XXXXXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+963111234567` | `+963 11 123 4567` | `011 123 4567` | Damascus — area code 11 |
| mobile | `+963933123456` | `+963 933 123 456` | `0933 123 456` | Mobile — 93 is a Syriatel range |

## Notes

- Closed plan with twelve regional area codes running from Damascus (11) to Al-Hasakah (52).
- The NSN is 9 digits: a 2-digit area or operator code plus a 7-digit subscriber number.
