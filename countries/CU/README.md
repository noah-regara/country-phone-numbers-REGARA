# Cuba — Phone Number Formats

**ISO 3166-1:** `CU` / `CUB`  
**Country calling code:** +53  
**Trunk prefix:** `0`  
**International call prefix:** `00`  
**National significant number:** 8 digits

## Formatting

```
National:      0A XXXXXXX (landline) / 5XXX XXXX (mobile)
International: +53 A XXXXXXX (trunk 0 dropped)
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Havana (7) | `07 XXXXXXX` | `+53 7 XXXXXXX` |
| Other provinces (2-digit area codes) | `0XX XXXXXX` | `+53 XX XXXXXX` |
| Mobile (5) | `5XXX XXXX` | `+53 5XXX XXXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+5371234567` | `+53 7 123 4567` | `07 123 4567` | Havana — area code 7 |
| mobile | `+5351234567` | `+53 5123 4567` | `5123 4567` | Mobile — all Cuban mobiles begin with 5 and carry no trunk prefix |

## Notes

- The NSN is 8 digits, with the first one or two forming the area code for fixed lines.
- Mobile numbers are dialled as a flat 8 digits beginning with 5, without the trunk 0.
