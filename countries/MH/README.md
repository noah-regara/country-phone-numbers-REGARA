# Marshall Islands — Phone Number Formats

**ISO 3166-1:** `MH` / `MHL`  
**Country calling code:** +692  
**Trunk prefix:** none  
**International call prefix:** `00`  
**National significant number:** 7 digits

## Formatting

```
National:      XXX XXXX
International: +692 XXX XXXX
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Fixed line — Majuro (247, 528), Ebeye (329) | `528 XXXX` | `+692 528 XXXX` |
| Mobile — GSM (455, 456) | `455 XXXX` | `+692 455 XXXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+6925281234` | `+692 528 1234` | `528 1234` | Majuro Atoll, Laura exchange — PSTN service |
| mobile | `+6924551234` | `+692 455 1234` | `455 1234` | Mobile — Majuro Atoll GSM range |

## Notes

- Closed 7-digit plan with geographic prefixes for Majuro, Ebeye and the outer atolls.
- Operated by the Marshall Islands National Telecommunications Authority.
