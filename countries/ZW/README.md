# Zimbabwe — Phone Number Formats

**ISO 3166-1:** `ZW` / `ZWE`  
**Country calling code:** +263  
**Trunk prefix:** `0`  
**International call prefix:** `00`  
**National significant number:** 9 digits

## Formatting

```
National:      0AA XXXXXXX
International: +263 AA XXXXXXX (trunk 0 dropped)
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Harare (024) | `024 2XXXXXX` | `+263 24 2XXXXXX` |
| Bulawayo (029) | `029 2XXXXXX` | `+263 29 2XXXXXX` |
| Mobile — Econet (077, 078), NetOne (071), Telecel (073) | `077 XXXXXXX` | `+263 77 XXXXXXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+263242123456` | `+263 24 2123456` | `024 2123456` | Harare — area code 024 with an added prefixing digit 2 |
| mobile | `+263771234567` | `+263 77 1234567` | `077 1234567` | Mobile — 077 is an Econet range |
| mobile | `+263712345678` | `+263 71 2345678` | `071 2345678` | Mobile — 071 is a NetOne range |

## Notes

- Zimbabwe restructured its geographic numbers by inserting a prefixing digit after the area code, giving a uniform 9-digit NSN.
- Area codes are 2–3 digits after the trunk 0.
