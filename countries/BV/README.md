# Bouvet Island — Phone Number Formats

**ISO 3166-1:** `BV` / `BVT`  
**Country calling code:** +47  
**Trunk prefix:** none  
**International call prefix:** `00`  
**National significant number:** variable

## Formatting

```
National:      no numbering assigned
International: no numbering assigned
```

## Examples

_No public numbering is assigned to this territory — see the notes below._

## Notes

- Bouvet Island is an uninhabited subantarctic dependency of Norway. It has no permanent population, no exchange and no telephone numbers.
- It is nominally associated with Norway's +47 country code, but no numbers are allocated to it and none are reachable.
- Any communication with expeditions on the island is by satellite.
