# Ecuador — Phone Number Formats

**ISO 3166-1:** `EC` / `ECU`  
**Country calling code:** +593  
**Trunk prefix:** `0`  
**International call prefix:** `00`  
**National significant number:** 8 or 9 digits

## Formatting

```
National:      (0A) XXX-XXXX (landline) / 09X XXX XXXX (mobile)
International: +593 A XXX XXXX (trunk 0 dropped)
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Quito / Pichincha (02) | `(02) XXX-XXXX` | `+593 2 XXX XXXX` |
| Guayaquil / Guayas (04), other provinces (03, 05, 06, 07) | `(04) XXX-XXXX` | `+593 4 XXX XXXX` |
| Mobile (09X) | `09X XXX XXXX` | `+593 9X XXX XXXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+59322111111` | `+593 2 211 1111` | `(02) 211-1111` | Quito — area code 2 covers Pichincha province |
| fixed-line | `+59341234567` | `+593 4 123 4567` | `(04) 123-4567` | Guayaquil — area code 4 |
| mobile | `+593991234567` | `+593 99 123 4567` | `099 123 4567` | Mobile — the 9 prefix denotes cellular; 92–99 identify networks |

## Notes

- Geographic area codes 2–7 map to provinces; the 9 prefix is reserved for mobile.
- Fixed NSNs are 8 digits and mobile NSNs 9.
