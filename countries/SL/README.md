# Sierra Leone — Phone Number Formats

**ISO 3166-1:** `SL` / `SLE`  
**Country calling code:** +232  
**Trunk prefix:** `0`  
**International call prefix:** `00`  
**National significant number:** 8 digits

## Formatting

```
National:      0YY XXXXXX
International: +232 YY XXXXXX (trunk 0 dropped)
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Fixed line — Sierratel, Freetown (22) | `022 XXXXXX` | `+232 22 XXXXXX` |
| Mobile — Airtel (76, 30), Orange (78, 79, 88) | `076 XXXXXX` | `+232 76 XXXXXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+23222212345` | `+232 22 212345` | `022 212345` | Freetown — area code 22 (Sierratel) |
| mobile | `+23276123456` | `+232 76 123456` | `076 123456` | Mobile — 76 is an Airtel Sierra Leone range |

## Notes

- The 8-digit NSN comprises a 2-digit area or operator code plus a 6-digit subscriber number.
- The trunk 0 is used domestically and dropped when dialling from abroad.
