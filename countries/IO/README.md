# British Indian Ocean Territory — Phone Number Formats

**ISO 3166-1:** `IO` / `IOT`  
**Country calling code:** +246  
**Trunk prefix:** none  
**International call prefix:** `00`  
**National significant number:** 7 digits

## Formatting

```
National:      XXX XXXX
International: +246 XXX XXXX
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Fixed line (37X XXXX) | `37X XXXX` | `+246 37X XXXX` |
| Mobile (38X XXXX) | `38X XXXX` | `+246 38X XXXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+2463709100` | `+246 370 9100` | `370 9100` | Diego Garcia — the 37X fixed range (this specific number is a network test tone) |
| mobile | `+2463801234` | `+246 380 1234` | `380 1234` | Mobile — the 38X range |

## Notes

- The British Indian Ocean Territory's only inhabited island is Diego Garcia, a joint UK–US military facility; there is no civilian population.
- Note the collision risk: +246 is the BIOT country code, while 246 is also the NANP area code for Barbados (+1 246). These are entirely different numbers.
- No area codes; the NSN is a flat 7 digits.
