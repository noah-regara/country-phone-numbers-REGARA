# Latvia — Phone Number Formats

**ISO 3166-1:** `LV` / `LVA`  
**Country calling code:** +371  
**Trunk prefix:** none  
**International call prefix:** `00`  
**National significant number:** 8 digits

## Formatting

```
National:      XX XXX XXX
International: +371 XX XXX XXX
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Fixed line (6xxxxxxx; 67x = Riga) | `67 XXX XXX` | `+371 67 XXX XXX` |
| Mobile (2xxxxxxx) | `2X XXX XXX` | `+371 2X XXX XXX` |
| Freephone | `80 XXX XXX` | `+371 80 XXX XXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+37167123456` | `+371 67 123 456` | `67 123 456` | Riga — the 67x block serves the Riga district |
| mobile | `+37121234567` | `+371 21 234 567` | `21 234 567` | Mobile — all Latvian mobiles begin with 2 |
| toll-free | `+37180123456` | `+371 80 123 456` | `80 123 456` | Freephone |

## Notes

- Latvia uses a closed 8-digit plan with no trunk prefix or separately dialled area codes.
- All fixed lines begin with 6 and all mobiles with 2 — a reform completed in 2008.
