# Guinea-Bissau — Phone Number Formats

**ISO 3166-1:** `GW` / `GNB`  
**Country calling code:** +245  
**Trunk prefix:** none  
**International call prefix:** `00`  
**National significant number:** 9 digits

## Formatting

```
National:      XX XXX XXXX
International: +245 XX XXX XXXX
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Fixed line — Guiné Telecom (44) | `44 XXX XXXX` | `+245 44 XXX XXXX` |
| Mobile — Orange Bissau (95X), MTN Areeba (96X, 97X) | `95X XXX XXX` | `+245 95X XXX XXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+245443301234` | `+245 44 330 1234` | `44 330 1234` | Bissau — the 44 fixed prefix (Guiné Telecom) |
| mobile | `+245955123456` | `+245 955 123 456` | `955 123 456` | Mobile — the 95X Orange Bissau range |

## Notes

- Closed 9-digit plan; the same digits are dialled domestically and after +245 from abroad.
- No trunk prefix or geographic area codes.
