# Botswana — Phone Number Formats

**ISO 3166-1:** `BW` / `BWA`  
**Country calling code:** +267  
**Trunk prefix:** none  
**International call prefix:** `00`  
**National significant number:** 7 or 8 digits

## Formatting

```
National:      XXX XXXX (fixed) / XX XXX XXX (mobile)
International: +267 XXX XXXX
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Fixed line — Gaborone (39x), Francistown (24x) | `39X XXXX` | `+267 39X XXXX` |
| Mobile — Mascom (71, 74), Orange (72, 75), beMobile (73, 76) | `71 XXX XXX` | `+267 71 XXX XXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+2673903650` | `+267 390 3650` | `390 3650` | Gaborone — the leading 39 identifies the area; there are no separate area codes |
| mobile | `+26771234567` | `+267 71 234 567` | `71 234 567` | Mobile — 71 is a Mascom Wireless range |
| mobile | `+26772345678` | `+267 72 345 678` | `72 345 678` | Mobile — 72 is an Orange Botswana range |

## Notes

- Botswana has no area codes or trunk prefix; geography is encoded in the first two or three digits of a 7-digit fixed number.
- Mobile numbers are 8 digits, one longer than fixed lines.
