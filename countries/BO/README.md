# Bolivia — Phone Number Formats

**ISO 3166-1:** `BO` / `BOL`  
**Country calling code:** +591  
**Trunk prefix:** none  
**International call prefix:** `00`  
**National significant number:** 8 digits

## Formatting

```
National:      A XXXXXXX
International: +591 A XXXXXXX
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| La Paz, Oruro, Potosí (2) | `2 XXXXXXX` | `+591 2 XXXXXXX` |
| Santa Cruz, Beni, Pando (3); Cochabamba, Chuquisaca, Tarija (4) | `3 XXXXXXX` | `+591 3 XXXXXXX` |
| Mobile (6, 7) | `7 XXXXXXX` | `+591 7 XXXXXXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+59122123456` | `+591 2 212 3456` | `2 2123456` | La Paz — area code 2 also covers Oruro and Potosí departments |
| mobile | `+59171234567` | `+591 7 123 4567` | `7 1234567` | Mobile — 6 and 7 are the mobile ranges |
| fixed-line | `+59133123456` | `+591 3 312 3456` | `3 3123456` | Santa Cruz — area code 3 |

## Notes

- Closed 8-digit plan; the leading digit is the area code (2, 3, 4 geographic; 5 national services; 6, 7 mobile).
- Administered by the ATT (Autoridad de Regulación y Fiscalización de Telecomunicaciones y Transportes).
