# New Zealand — Phone Number Formats

**ISO 3166-1:** `NZ` / `NZL`  
**Country calling code:** +64  
**Trunk prefix:** `0`  
**International call prefix:** `00`  
**National significant number:** 8 or 9 digits

## Formatting

```
National:      (0A) XXX XXXX (landline) / 02X XXX XXXX (mobile)
International: +64 A XXX XXXX (trunk 0 dropped)
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Auckland / Northland (09) | `(09) XXX XXXX` | `+64 9 XXX XXXX` |
| Wellington (04), Waikato/BoP (07), Taranaki–Hawke's Bay (06), South Island (03) | `(04) XXX XXXX` | `+64 4 XXX XXXX` |
| Mobile (021, 022, 027) | `021 XXX XXXX` | `+64 21 XXX XXXX` |
| Toll-free | `0800 XXX XXX` | `+64 800 XXX XXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+6497001234` | `+64 9 700 1234` | `(09) 700 1234` | Auckland — area code 09 covers Auckland and Northland |
| fixed-line | `+6441234567` | `+64 4 123 4567` | `(04) 123 4567` | Wellington — area code 04 |
| mobile | `+64212345678` | `+64 21 234 5678` | `021 234 5678` | Mobile — 021 is a One NZ range; 022 and 027 are also mobile |
| toll-free | `+64800123456` | `+64 800 123 456` | `0800 123 456` | Toll-free |

## Notes

- New Zealand has five geographic area codes (03, 04, 06, 07, 09) covering large regions; landline NSNs are 8 digits.
- Mobile subscriber numbers vary in length, giving mobile NSNs of 9 (sometimes 8 or 10) digits.
