# Bhutan — Phone Number Formats

**ISO 3166-1:** `BT` / `BTN`  
**Country calling code:** +975  
**Trunk prefix:** none  
**International call prefix:** `00`  
**National significant number:** 7 or 8 digits

## Formatting

```
National:      X XXXXXX (fixed) / XX XXXXXX (mobile)
International: +975 X XXXXXX
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Thimphu (2) | `2 XXXXXX` | `+975 2 XXXXXX` |
| Other dzongkhags (3–8) | `X XXXXXX` | `+975 X XXXXXX` |
| Mobile — B-Mobile (17), TashiCell (77) | `17 XXXXXX` | `+975 17 XXXXXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+9752123456` | `+975 2 123456` | `2 123456` | Thimphu — area code 2 |
| mobile | `+97517123456` | `+975 17 123456` | `17 123456` | Mobile — 17 is a B-Mobile range |

## Notes

- Closed plan with no trunk prefix. Fixed NSNs are 7 digits (1-digit area code + 6) and mobile NSNs 8 (2-digit operator code + 6).
