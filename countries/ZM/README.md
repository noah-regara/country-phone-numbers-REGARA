# Zambia — Phone Number Formats

**ISO 3166-1:** `ZM` / `ZMB`  
**Country calling code:** +260  
**Trunk prefix:** `0`  
**International call prefix:** `00`  
**National significant number:** 9 digits

## Formatting

```
National:      0AAA XXXXXX
International: +260 AAA XXXXXX (trunk 0 dropped)
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Lusaka Province (0211) | `0211 XXXXXX` | `+260 211 XXXXXX` |
| Other provinces (212–218) | `021X XXXXXX` | `+260 21X XXXXXX` |
| Mobile — MTN (096, 076), Airtel (097, 077), Zamtel (095, 075) | `0961 XXXXXX` | `+260 961 XXXXXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+260211123456` | `+260 211 123456` | `0211 123456` | Lusaka Province — area code 211 (ZAMTEL) |
| mobile | `+260961234567` | `+260 961 234567` | `0961 234567` | Mobile — 096/076 are MTN Zambia ranges |
| mobile | `+260971234567` | `+260 971 234567` | `0971 234567` | Mobile — 097/077 are Airtel Zambia ranges |

## Notes

- Geographic area codes 211–218 map to Zambia's provinces.
- Mobile prefixes 095/096/097 (and the newer 075/076/077 blocks) identify the operator.
