# Ghana — Phone Number Formats

**ISO 3166-1:** `GH` / `GHA`  
**Country calling code:** +233  
**Trunk prefix:** `0`  
**International call prefix:** `00`  
**National significant number:** 9 digits

## Formatting

```
National:      0AA XXX XXXX
International: +233 AA XXX XXXX (trunk 0 dropped)
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Greater Accra (030) | `030 2XXXXXX` | `+233 30 2XXXXXX` |
| Kumasi / Ashanti (032) | `032 XXXXXXX` | `+233 32 XXXXXXX` |
| Mobile (020, 023, 024, 026, 027, 028, 050, 054, 055, 059) | `024 XXX XXXX` | `+233 24 XXX XXXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+233302123456` | `+233 30 2123456` | `030 2123456` | Accra — regional code 030 with '2' designating Accra itself |
| mobile | `+233241234567` | `+233 24 123 4567` | `024 123 4567` | Mobile — 024 is an MTN Ghana range |
| mobile | `+233201234567` | `+233 20 123 4567` | `020 123 4567` | Mobile — 020 range |

## Notes

- Since 2010-05-01 all Ghanaian fixed and mobile numbers have a uniform 9-digit NSN.
- Administered by the National Communications Authority.
