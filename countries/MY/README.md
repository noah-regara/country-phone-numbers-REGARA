# Malaysia — Phone Number Formats

**ISO 3166-1:** `MY` / `MYS`  
**Country calling code:** +60  
**Trunk prefix:** `0`  
**International call prefix:** `00`  
**National significant number:** 8 or 9 or 10 digits

## Formatting

```
National:      0A-XXXX XXXX (landline) / 01X-XXX XXXX (mobile)
International: +60 A XXXX XXXX (trunk 0 dropped)
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Kuala Lumpur / Selangor (03) | `03-XXXX XXXX` | `+60 3 XXXX XXXX` |
| Other states (04 Penang, 07 Johor, 088 Sabah) | `04-XXX XXXX` | `+60 4 XXX XXXX` |
| Mobile (010–019) | `012-XXX XXXX` | `+60 12 XXX XXXX` |
| Toll-free | `1800-XX-XXXX` | `not reachable from abroad` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+60321234567` | `+60 3 2123 4567` | `03-2123 4567` | Kuala Lumpur — area code 03, the largest block |
| fixed-line | `+6041234567` | `+60 4 123 4567` | `04-123 4567` | Penang — area code 04 |
| mobile | `+60123456789` | `+60 12 345 6789` | `012-345 6789` | Mobile — 010–019 ranges |

## Notes

- Malaysia uses an open plan: landline area codes are 1–2 digits with 6–8 subscriber digits; mobile codes are 2 digits with 7–8 subscriber digits.
- Until 2017 Singapore could be dialled from Malaysia as a domestic call using the 02 code; that arrangement ended and +65 international dialling is now required.
