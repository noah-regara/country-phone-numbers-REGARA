# Mexico — Phone Number Formats

**ISO 3166-1:** `MX` / `MEX`  
**Country calling code:** +52  
**Trunk prefix:** none  
**International call prefix:** `00`  
**National significant number:** 10 digits

## Formatting

```
National:      AA XXXX XXXX (2-digit area code) / AAA XXX XXXX (3-digit area code)
International: +52 AA XXXX XXXX
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Mexico City (55), Monterrey (81), Guadalajara (33) | `55 XXXX XXXX` | `+52 55 XXXX XXXX` |
| Other cities (3-digit area codes) | `XXX XXX XXXX` | `+52 XXX XXX XXXX` |
| Toll-free | `800 XXX XXXX` | `+52 800 XXX XXXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+525512345678` | `+52 55 1234 5678` | `55 1234 5678` | Mexico City — area code 55 |
| fixed-line | `+523312345678` | `+52 33 1234 5678` | `33 1234 5678` | Guadalajara — area code 33 |
| mobile | `+525598765432` | `+52 55 9876 5432` | `55 9876 5432` | Mobile — since the 2019 reform mobiles share geographic area codes and are indistinguishable by format |
| toll-free | `+528001234567` | `+52 800 123 4567` | `800 123 4567` | Toll-free |

## Notes

- Mexico reformed its plan on 2019-08-03: all calls now use a uniform 10-digit number and the old prefixes 01 (long distance), 044 and 045 (mobile) were abolished.
- Since the reform, mobile and fixed numbers are drawn from the same area codes and cannot be told apart by format alone — the +521 mobile prefix once required from abroad is also obsolete.
- The first digit of the area code indicates a broad region: 2 East, 3 West, 4 North, 5 Centre, 6 Northwest, 7 South, 8 Northeast, 9 Southeast.
