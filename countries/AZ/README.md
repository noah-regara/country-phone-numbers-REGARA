# Azerbaijan — Phone Number Formats

**ISO 3166-1:** `AZ` / `AZE`  
**Country calling code:** +994  
**Trunk prefix:** `0`  
**International call prefix:** `00`  
**National significant number:** 9 digits

## Formatting

```
National:      0AA XXX XX XX
International: +994 AA XXX XX XX (trunk 0 dropped)
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Baku (12) | `012 XXX XX XX` | `+994 12 XXX XX XX` |
| Other regions (2-digit area codes) | `0XX XXX XX XX` | `+994 XX XXX XX XX` |
| Mobile (50–55 Azercell, 55–59/99 Bakcell, 70 Nar) | `050 XXX XX XX` | `+994 50 XXX XX XX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+994124980335` | `+994 12 498 03 35` | `012 498 03 35` | Baku — area code 12 |
| mobile | `+994501234567` | `+994 50 123 45 67` | `050 123 45 67` | Mobile — 50 is an Azercell range |
| mobile | `+994701234567` | `+994 70 123 45 67` | `070 123 45 67` | Mobile — 70 is a Nar Mobile range |

## Notes

- Closed 9-digit plan: a 2-digit area or operator code plus a 7-digit subscriber number.
- Mobile operator prefixes: 50/51 Azercell, 55/99 Bakcell, 70/77 Nar Mobile.
