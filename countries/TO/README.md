# Tonga — Phone Number Formats

**ISO 3166-1:** `TO` / `TON`  
**Country calling code:** +676  
**Trunk prefix:** none  
**International call prefix:** `00`  
**National significant number:** 5 or 7 digits

## Formatting

```
National:      XX XXX
International: +676 XX XXX
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Fixed line — Nukuʻalofa (20–29) | `20 XXX` | `+676 20 XXX` |
| Mobile (77, 84, 87, 88) | `87 XXX` | `+676 87 XXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+67620123` | `+676 20 123` | `20 123` | Nukuʻalofa — area code 20 |
| mobile | `+67687456` | `+676 87 456` | `87 456` | Mobile — Tongatapu island group, prefix 87 |

## Notes

- Tonga uses a short 5-digit NSN: a 2-digit area code plus a 3-digit local number. Some newer mobile ranges have been extended to 7 digits.
- No trunk prefix — the full number is dialled for every domestic call.
