# Thailand — Phone Number Formats

**ISO 3166-1:** `TH` / `THA`  
**Country calling code:** +66  
**Trunk prefix:** `0`  
**International call prefix:** `00`  
**National significant number:** 8 or 9 digits

## Formatting

```
National:      0A-XXX-XXXX (landline) / 0AX-XXX-XXXX (mobile)
International: +66 A XXX XXXX (trunk 0 dropped)
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Bangkok (02) | `02-XXX-XXXX` | `+66 2 XXX XXXX` |
| Provincial (2-digit area codes: 032 Phetchaburi, 053 Chiang Mai) | `0XX-XXX-XXX` | `+66 XX XXX XXX` |
| Mobile (08x, 09x, 06x) | `08X-XXX-XXXX` | `+66 8X XXX XXXX` |
| Toll-free | `1800-XXX-XXX` | `not reachable from abroad` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+6622134567` | `+66 2 213 4567` | `02-213-4567` | Bangkok — area code 02 also covers nearby provinces |
| fixed-line | `+6653123456` | `+66 53 123 456` | `053-123-456` | Chiang Mai — area code 053 |
| mobile | `+66812345678` | `+66 81 234 5678` | `081-234-5678` | Mobile — 08x, 09x and 06x ranges |

## Notes

- Thailand uses a closed plan: the area code must be dialled even for calls within the same area.
- Bangkok has the single-digit area code 2 with a 7-digit subscriber number; provinces have 2-digit codes with 6-digit subscriber numbers.
- 1800 toll-free numbers are domestic-only and cannot be reached from abroad.
