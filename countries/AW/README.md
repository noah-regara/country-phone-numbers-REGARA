# Aruba — Phone Number Formats

**ISO 3166-1:** `AW` / `ABW`  
**Country calling code:** +297  
**Trunk prefix:** none  
**International call prefix:** `00`  
**National significant number:** 7 digits

## Formatting

```
National:      XXX XXXX
International: +297 XXX XXXX
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Fixed line (28, 52, 58) | `58X XXXX` | `+297 58X XXXX` |
| Mobile (56, 59, 64, 73, 74, 99) | `56X XXXX` | `+297 56X XXXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+2975821234` | `+297 582 1234` | `582 1234` | Fixed line — the 58 range |
| mobile | `+2975601234` | `+297 560 1234` | `560 1234` | Mobile — the 56 range |

## Notes

- Aruba left the Netherlands Antilles plan (+599 8) in 1986 and took its own code +297.
- Although the 7-digit format resembles a NANP local number, Aruba is not part of the NANP — calls are international.
