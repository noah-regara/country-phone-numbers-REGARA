# Turkmenistan — Phone Number Formats

**ISO 3166-1:** `TM` / `TKM`  
**Country calling code:** +993  
**Trunk prefix:** `8`  
**International call prefix:** `810`  
**National significant number:** 8 digits

## Formatting

```
National:      8 AA XX-XX-XX
International: +993 AA XX XX XX
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Ashgabat (12) | `8 12 XX-XX-XX` | `+993 12 XX XX XX` |
| Other regions (2-digit area codes) | `8 XX XX-XX-XX` | `+993 XX XX XX XX` |
| Mobile — Altyn Asyr (61–65, 71) | `8 6X XX-XX-XX` | `+993 6X XX XX XX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+99312345678` | `+993 12 34 56 78` | `8 12 34-56-78` | Ashgabat — area code 12 |
| mobile | `+99361234567` | `+993 61 23 45 67` | `8 61 23-45-67` | Mobile — 61–65 are Altyn Asyr ranges |

## Notes

- Turkmenistan retains the Soviet-era trunk prefix 8 and 8~10 international access.
- The 8-digit NSN is conventionally written in 2-2-2-2 groups.
