# Papua New Guinea — Phone Number Formats

**ISO 3166-1:** `PG` / `PNG`  
**Country calling code:** +675  
**Trunk prefix:** none  
**International call prefix:** `00`  
**National significant number:** 7 or 8 digits

## Formatting

```
National:      XXX XXXX (fixed) / XXXX XXXX (mobile)
International: +675 XXX XXXX
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Fixed line — Port Moresby (300–303) | `300 XXXX` | `+675 300 XXXX` |
| Mobile — Digicel (70–79, 88), bmobile (75–77), Vodafone (81–84) | `70XX XXXX` | `+675 70XX XXXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+6753001234` | `+675 300 1234` | `300 1234` | Port Moresby — the 300–303 block serves the National Capital District |
| mobile | `+67570123456` | `+675 7012 3456` | `7012 3456` | Mobile — 8 digits, one more than a fixed line; 70–79 are Digicel PNG ranges |

## Notes

- Fixed NSNs are 7 digits and mobile NSNs 8, so length distinguishes the two.
- The international access prefix changed from 05 to 00 in 2010.
