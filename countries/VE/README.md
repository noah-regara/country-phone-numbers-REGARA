# Venezuela, Bolivarian Republic of — Phone Number Formats

**ISO 3166-1:** `VE` / `VEN`  
**Country calling code:** +58  
**Trunk prefix:** `0`  
**International call prefix:** `00`  
**National significant number:** 10 digits

## Formatting

```
National:      0AAA XXXXXXX
International: +58 AAA XXXXXXX (trunk 0 dropped)
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Caracas / Distrito Capital (212) | `0212 XXXXXXX` | `+58 212 XXXXXXX` |
| Other states (3-digit area codes) | `0XXX XXXXXXX` | `+58 XXX XXXXXXX` |
| Mobile (412 Digitel, 414/424 Movistar, 416/426 Movilnet) | `0412 XXXXXXX` | `+58 412 XXXXXXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+582125551212` | `+58 212 555 1212` | `0212 5551212` | Caracas — area code 212 |
| mobile | `+584121234567` | `+58 412 123 4567` | `0412 1234567` | Mobile — 412 is a Digitel range |
| mobile | `+584141234567` | `+58 414 123 4567` | `0414 1234567` | Mobile — 414/424 are Movistar ranges |

## Notes

- Closed 10-digit plan: a 3-digit area code plus a 7-digit subscriber number. The plan was last revised on 2000-09-21.
- Mobile operator codes fall in the 412–426 range.
- Numbers beginning with 5 are region-free and billed as local calls nationwide.
