# South Sudan — Phone Number Formats

**ISO 3166-1:** `SS` / `SSD`  
**Country calling code:** +211  
**Trunk prefix:** none  
**International call prefix:** `00`  
**National significant number:** 9 digits

## Formatting

```
National:      MM NNN NNNN
International: +211 MM NNN NNNN
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Fixed — Sudani CDMA (12), Sudani landline (18) | `18 NNN NNNN` | `+211 18 NNN NNNN` |
| Mobile — Zain (91), MTN (92), Digitel (98) | `91 NNN NNNN` | `+211 91 NNN NNNN` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+211181111111` | `+211 18 111 1111` | `18 111 1111` | Juba — Sudani fixed service, prefix 18 |
| mobile | `+211915555555` | `+211 91 555 5555` | `91 555 5555` | Mobile — 91 is a Zain South Sudan range |
| mobile | `+211921234567` | `+211 92 123 4567` | `92 123 4567` | Mobile — 92 is an MTN South Sudan range |

## Notes

- South Sudan continued using Sudan's +249 after independence on 2011-07-09 and switched to its own code +211 on 2011-10-01.
- The NSN is 9 digits: a 2-digit operator code plus a 7-digit subscriber number.
