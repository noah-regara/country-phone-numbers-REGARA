# Cocos (Keeling) Islands — Phone Number Formats

**ISO 3166-1:** `CC` / `CCK`  
**Country calling code:** +61  
**Trunk prefix:** `0`  
**International call prefix:** `0011`  
**National significant number:** 9 digits

## Formatting

```
National:      (08) 9162 XXXX
International: +61 8 9162 XXXX (trunk 0 dropped)
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Cocos (Keeling) Islands (08 9162) | `(08) 9162 XXXX` | `+61 8 9162 XXXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+61891621234` | `+61 8 9162 1234` | `(08) 9162 1234` | Cocos (Keeling) Islands — the dedicated 9162 exchange within Australia's 08 area code |

## Notes

- The Cocos (Keeling) Islands are an Australian external territory inside the +61 plan; they have no country code of their own.
- They used +672 until October 1994, when they migrated to +61 and eventually settled on the 08 9162 range.
- Christmas Island uses the adjacent 08 9164 range.
