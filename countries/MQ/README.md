# Martinique — Phone Number Formats

**ISO 3166-1:** `MQ` / `MTQ`  
**Country calling code:** +596  
**Trunk prefix:** `0`  
**International call prefix:** `00`  
**National significant number:** 9 digits

## Formatting

```
National:      0596 XX XX XX
International: +596 596 XX XX XX
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Fixed line (0596) | `0596 XX XX XX` | `+596 596 XX XX XX` |
| Mobile (0696, 0697) | `0696 XX XX XX` | `+596 696 XX XX XX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+596596123456` | `+596 596 12 34 56` | `0596 12 34 56` | Martinique fixed — the country code repeats as the internal area code |
| mobile | `+596696123456` | `+596 696 12 34 56` | `0696 12 34 56` | Mobile — the 0696 range |

## Notes

- Martinique follows the French 10-digit national format; +596 596 xx xx xx repeats the code by design.
- Numbers are written in pairs in the French style.
