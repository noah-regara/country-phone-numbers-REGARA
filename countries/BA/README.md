# Bosnia and Herzegovina — Phone Number Formats

**ISO 3166-1:** `BA` / `BIH`  
**Country calling code:** +387  
**Trunk prefix:** `0`  
**International call prefix:** `00`  
**National significant number:** 8 digits

## Formatting

```
National:      0AA XXX XXX
International: +387 AA XXX XXX (trunk 0 dropped)
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Sarajevo (033) | `033 XXX XXX` | `+387 33 XXX XXX` |
| Banja Luka (051), Mostar (036) | `051 XXX XXX` | `+387 51 XXX XXX` |
| Mobile (60–66) | `061 XXX XXX` | `+387 61 XXX XXX` |
| Freephone | `0800 XXXXX` | `+387 800 XXXXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+38733123456` | `+387 33 123 456` | `033 123 456` | Sarajevo — area code 033 |
| fixed-line | `+38751123456` | `+387 51 123 456` | `051 123 456` | Banja Luka — area code 051 |
| mobile | `+38761234567` | `+387 61 234 567` | `061 234 567` | Mobile — 61 is a BH Mobile range |
| toll-free | `+38780020002` | `+387 800 20002` | `0800 20002` | Freephone |

## Notes

- Bosnia and Herzegovina uses 8-digit NSNs: a 2-digit area code plus a 6-digit subscriber number.
- Area codes broadly follow the entity structure — 033 Sarajevo, 051 Banja Luka, 036 Mostar.
