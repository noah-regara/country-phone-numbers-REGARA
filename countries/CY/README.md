# Cyprus — Phone Number Formats

**ISO 3166-1:** `CY` / `CYP`  
**Country calling code:** +357  
**Trunk prefix:** none  
**International call prefix:** `00`  
**National significant number:** 8 digits

## Formatting

```
National:      XX XXXXXX
International: +357 XX XXXXXX
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Nicosia (22), Limassol (25), Larnaca (24), Paphos (26) | `22 XXXXXX` | `+357 22 XXXXXX` |
| Mobile (9X) | `9X XXXXXX` | `+357 9X XXXXXX` |
| Freephone | `800 XXXXX` | `+357 800 XXXXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+35722123456` | `+357 22 123456` | `22 123456` | Nicosia — district code 22 |
| fixed-line | `+35725123456` | `+357 25 123456` | `25 123456` | Limassol — district code 25 |
| mobile | `+35796123456` | `+357 96 123456` | `96 123456` | Mobile — 9x; the second digit identifies the carrier (7 CYTA, 6 Epic, 5 PrimeTel, 4 Cablenet) |

## Notes

- Cyprus uses a closed 8-digit plan with no trunk prefix; district codes are dialled as part of the number.
- Northern Cyprus is not covered by +357: it is integrated into the Turkish numbering plan and reached as +90 392.
