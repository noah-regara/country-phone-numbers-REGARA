# Chad — Phone Number Formats

**ISO 3166-1:** `TD` / `TCD`  
**Country calling code:** +235  
**Trunk prefix:** none  
**International call prefix:** `00`  
**National significant number:** 8 digits

## Formatting

```
National:      XX XX XX XX
International: +235 XX XX XX XX
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Fixed line — N'Djamena (2251) | `22 51 XX XX` | `+235 22 51 XX XX` |
| Mobile — Airtel (66), Moov (63), Sotel (9X) | `66 XX XX XX` | `+235 66 XX XX XX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+23522511234` | `+235 22 51 12 34` | `22 51 12 34` | N'Djamena — the 2251 block serves the capital |
| mobile | `+23566123456` | `+235 66 12 34 56` | `66 12 34 56` | Mobile — 66 is an Airtel Chad range |

## Notes

- Closed 8-digit plan with no trunk prefix; the first four digits act as the area or operator code.
- Numbers are written in pairs in the French style.
