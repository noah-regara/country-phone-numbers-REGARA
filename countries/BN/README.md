# Brunei Darussalam — Phone Number Formats

**ISO 3166-1:** `BN` / `BRN`  
**Country calling code:** +673  
**Trunk prefix:** none  
**International call prefix:** `00`  
**National significant number:** 7 digits

## Formatting

```
National:      XXX XXXX
International: +673 XXX XXXX
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Fixed line (20X–29X, 3XX–5XX) | `22X XXXX` | `+673 22X XXXX` |
| Mobile (7XX, 8XX) | `7XX XXXX` | `+673 7XX XXXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+6732234567` | `+673 223 4567` | `223 4567` | Fixed line — the 22X block |
| mobile | `+6737123456` | `+673 712 3456` | `712 3456` | Mobile — 7XX and 8XX ranges |

## Notes

- Brunei removed its trunk prefix and area codes on 2003-03-22, moving to a flat closed 7-digit plan.
- The old area codes (02 Bandar Seri Begawan, 03 Seria/Kuala Belait) survive only as the leading digits of the number.
