# Guinea — Phone Number Formats

**ISO 3166-1:** `GN` / `GIN`  
**Country calling code:** +224  
**Trunk prefix:** none  
**International call prefix:** `00`  
**National significant number:** 8 or 9 digits

## Formatting

```
National:      XXX XX XX XX
International: +224 XXX XX XX XX
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Fixed line — Conakry (30 4X) | `30 4X XX XX` | `+224 30 4X XX XX` |
| Mobile — Orange (62X), MTN/Areeba (66X), Cellcom (65X) | `62X XX XX XX` | `+224 62X XX XX XX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+22430411234` | `+224 3041 1234` | `3041 1234` | Conakry — the 3041 fixed block serves the capital |
| mobile | `+224622123456` | `+224 622 123 456` | `622 123 456` | Mobile — 62X is an Orange Guinée range; mobile NSNs are 9 digits |

## Notes

- Fixed NSNs are 8 digits and mobile NSNs 9, so length distinguishes the two.
- No trunk prefix; numbers are dialled in full.
