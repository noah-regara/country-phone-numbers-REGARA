# Solomon Islands — Phone Number Formats

**ISO 3166-1:** `SB` / `SLB`  
**Country calling code:** +677  
**Trunk prefix:** none  
**International call prefix:** `00`  
**National significant number:** 5 or 7 digits

## Formatting

```
National:      XXXXX (fixed) / XXX XXXX (mobile)
International: +677 XXXXX
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Fixed line — Honiara (1xxxx) | `XXXXX` | `+677 XXXXX` |
| Mobile (74xxxxx, 75xxxxx, 7xxxxxx) | `740 XXXX` | `+677 740 XXXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+67721234` | `+677 21234` | `21234` | Honiara — fixed lines are 5 digits |
| mobile | `+6777401234` | `+677 740 1234` | `740 1234` | Mobile — 7 digits, in the 74xxxxx prepaid range |

## Notes

- Fixed NSNs are 5 digits and mobile NSNs 7.
- Honiara holds several dedicated fixed blocks; regional centres such as Auki, Gizo and Lata have their own.
