# Isle of Man — Phone Number Formats

**ISO 3166-1:** `IM` / `IMN`  
**Country calling code:** +44  
**Trunk prefix:** `0`  
**International call prefix:** `00`  
**National significant number:** 10 digits

## Formatting

```
National:      01624 XXXXXX
International: +44 1624 XXXXXX (trunk 0 dropped)
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Fixed line | `01624 XXXXXX` | `+44 1624 XXXXXX` |
| Mobile (Manx-allocated) | `07624 XXXXXX` | `+44 7624 XXXXXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+441624123456` | `+44 1624 123456` | `01624 123456` | Isle of Man — area code 01624 |
| mobile | `+447624123456` | `+44 7624 123456` | `07624 123456` | Mobile — 07624 is the Manx-allocated range |

## Notes

- The Isle of Man is a Crown Dependency sharing the +44 country code and UK numbering plan.
- All Manx landlines use area code 01624 and Manx mobiles use 07624, making the island unusually easy to identify by prefix.
- Manx numbers are often excluded from UK inclusive call allowances.
