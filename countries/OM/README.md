# Oman — Phone Number Formats

**ISO 3166-1:** `OM` / `OMN`  
**Country calling code:** +968  
**Trunk prefix:** none  
**International call prefix:** `00`  
**National significant number:** 8 digits

## Formatting

```
National:      XXXX XXXX (4-digit NDC + 4-digit line number)
International: +968 XXXX XXXX
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Fixed line — Muscat (24xx) | `24XX XXXX` | `+968 24XX XXXX` |
| Mobile — Omantel (91xx–95xx), Ooredoo (95xx–99xx) | `9XXX XXXX` | `+968 9XXX XXXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+96824212345` | `+968 2421 2345` | `2421 2345` | Muscat — the 24xx block is Omantel fixed service |
| mobile | `+96891234567` | `+968 9123 4567` | `9123 4567` | Mobile — 91xx is an Omantel range |
| mobile | `+96895342109` | `+968 9534 2109` | `9534 2109` | Mobile — 95xx is an Ooredoo Oman range |

## Notes

- Oman's 8-digit NSN splits into a 4-digit national destination code and a 4-digit line number.
- No trunk prefix; the full 8 digits are dialled for every domestic call.
