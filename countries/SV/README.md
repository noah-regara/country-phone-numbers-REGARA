# El Salvador — Phone Number Formats

**ISO 3166-1:** `SV` / `SLV`  
**Country calling code:** +503  
**Trunk prefix:** none  
**International call prefix:** `00`  
**National significant number:** 8 digits

## Formatting

```
National:      XXXX-XXXX
International: +503 XXXX XXXX
```

## Number ranges

| Range | National format | International format |
| --- | --- | --- |
| Fixed line (2) | `2XXX-XXXX` | `+503 2XXX XXXX` |
| Mobile (6, 7) | `7XXX-XXXX` | `+503 7XXX XXXX` |

## Examples

| Type | E.164 | International | National | Notes |
| --- | --- | --- | --- | --- |
| fixed-line | `+50322458901` | `+503 2245 8901` | `2245-8901` | Metropolitan fixed line — NDC 2, with the second digit marking the metro area |
| mobile | `+50370123456` | `+503 7012 3456` | `7012-3456` | Mobile — NDCs 6 and 7 are non-geographic |

## Notes

- The plan was updated in 2005: fixed services use NDC 2, mobile services NDCs 6 and 7.
- No trunk prefix or area codes.
